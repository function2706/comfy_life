# Comfy LIFE

リアル時刻に合わせて、キャラクターと一緒に暮らすアプリです。
コマンドを実行するたびに、ComfyUI でその場面の画像を生成して表示します。

## 起動

```
python server.py            # http://127.0.0.1:8765/ がブラウザで開く
python server.py --port 9000 --no-browser
```

`start.bat` をダブルクリックしても起動できます。
内職パズルとミニゲームを本体のデータに触れずに続けて試す単独版は、`puzzle_lab.bat`（ポート 8790）と `minigame_lab.bat`（ポート 8791）で起動できます（`python tools/puzzle_lab.py` / `python tools/minigame_lab.py` と同じ）。
必要なのは Python 3.8 以上だけです（追加パッケージは不要）。

最初に **設定 → 画像生成 (ComfyUI)** を開き、次の順で設定してください。

1. ComfyUI のアドレスとポートを入力する
2. 接続テストを実行する
3. チェックポイントを選んで保存する

画面右上の **📖 説明書** で、図入りの説明書（`static/manual.html`）が開きます。
設定画面では、項目名の横の ⓘ にマウスを乗せると説明が出て、各画面の 📖 で説明書の該当箇所に飛べます。左の並びは範囲ごとに分かれていて（あなた／キャラごと／全員共通（全ワールド）／このワールドの決まり（時間帯・数値を含む）／画像・文章／表示・データ）、キャラごとの設定（基本・外見・生活スケジュール・着せ替え）は「キャラクター」の中のタブです。編集するキャラの選択に従うのはこのタブだけで、性格・セリフ集などはキャラの選択とは関係ありません。

### 内職のパズルを単独で試す

本体では内職は 1 回ごとに 30 分休憩になるので、パズルだけを続けて試すときは単独版を使います（本体とは別の小さなサーバ）。

```
python tools/minigame_lab.py  ミニゲームの単独版（セリフ・画像なしで、条件に関係なく続けて遊ぶ）
tools/test_minigame_lab.py  ミニゲームの単独版のテスト（全ゲームを始められる・セリフを返さない・data/ に書かない・画面の共通化）
tools/puzzle_lab.py            # http://127.0.0.1:8790/ がブラウザで開く
python tools/puzzle_lab.py --port 8791 --no-browser
```

- 種類（マインスイーパ・数独・ピクロス・スリザーリンク・15パズル・2048・タイピング・フリーセル・スパイダーソリティア・クロンダイク）と難しさを選んで、何度でも続けて遊べます。本体と同じ「⏸ 一時停止」も使えます。すぐ新しい盤面、答えを表示、同じ seed で同じ盤面を出し直せます。
- 終えると、かかった時間・ミスと、本体ならいくら稼げたか（入れた仕事スキルで試算）を出します。履歴も残ります（ページを閉じるまで）。
- 盤面の生成と答え合わせは本体と同じ `core/puzzles.py`、画面は本体の内職と同じ `static/puzzles.js` です（ページは `static/puzzle_lab.html`）。ゲームの状態（お金・体力・休憩・スキル・ワールド）には一切触れず、`data/` にも書きません。

### ミニゲームを単独で遊ぶ

本体ではミニゲームは相手の機嫌や間柄・時間帯しだいで遊べないことがあるので、遊び心地や画面だけを確かめるときは単独版を使います（セリフ・画像なしで、ミニゲームをするだけ）。

```
python tools/minigame_lab.py          # http://127.0.0.1:8791/ がブラウザで開く
python tools/minigame_lab.py --port 8792 --no-browser
```

- 12 種類のミニゲームを、条件やクールダウンに関係なく何度でも続けて遊べます。相手は「相手」と表示し、セリフ・画像・相手の様子のヒントは出しません。
- ゲームの中身（ルール・相手の打ち方）は本体と同じ `core/games.py`、画面は本体のゲームタブと同じ `static/minigames.js` です（ページは `static/minigame_lab.html`）。
- 本体のデータには触れません。起動のたびに一時フォルダに使い捨ての世界を作り、終わったら消します（`data/` には書きません）。

会話欄が画像に被るときは、💬 ボタン・H キー・画像のクリックで一時的に隠せます。位置（上・下・画像の下に分ける）、濃さ、文字の大きさ、自動で隠す設定は **設定 → 表示** で変えられます（ブラウザごとに保存）。

### お出かけ・見るコマンド

- お出かけには、散歩・買い物・デート・ピクニック・ハイキング・海・遊園地・水族館・カフェ・星を見に行く、があります。
  - 季節によって反応が変わります（例: 冬の海）。季節は条件キー `season` で判定します。
- お出かけ中は「家に帰る」、ゲームや映画などの最中は「切り上げる」で、いつでも予定どおりの過ごし方に戻れます。
- 出かけるときはキャラクターの「お出かけ着」に着替えます。着せ替えで選んだ服は、「外に着ていける」にした服だけ、そのまま着ていきます（部屋着やパジャマのまま出かけません）。大胆な服のまま出かけるのは、性格と場所しだいで嫌がって着替えることがあります。
- **服の一覧と持っている服**（`core/wardrobe.py`）: 服は全員共通の一覧にあり、キャラは持っている服（`clothes: [{id, from: default / player / self, pos?, neg?}]`）だけを着る。
  - 大胆な服を着てくれるか（`Wardrobe.accept`）: 好感度・信頼・間柄（`STAGE_BONUS`）・性格の恥じらい（`traits.modesty`。-8〜10、控えめ）・その日の機嫌・場所（家の外は要る気持ちが大胆さ × 12、ほかに人がいれば × 6）・揺らぎ。仲が深くても「今日はそういう気分じゃない」（大胆さ × 4%）があり、2 時間以内に 2 回断られたのに頼むと怒る（`dress_asks`）。数値の目安: 水着（大胆さ 2）は浅い仲でほぼ断られ、深い仲で 9 割ほど、深い仲でも外では 6 割ほど。
  - 服を贈る: 値段のある服は店の品物（持ち物の `outfit:<id>`）になり、買うものリストで買ってプレゼントできる。受け取るか（`gift_feel`: 着るより一段易しい）で反応の条件 `gift_outfit`（yes / bold_no）。受け取ると持っている服に（`from: player`）、断られたら手元に残る。持っている服は贈れない。
  - 本人の服選び（`self_pick`）: 頼まれていないとき、予定に服の指定が無い場面（普段着・お出かけ着）では、その日・場面ごとに 55% ほど持っている服から自分で選ぶ（季節に合うもの・自分から着る大胆さの上限 `comfort` まで。雨の日の外出はよそ行きを避けがち。あなたが贈った服は仲しだいで選ばれやすい）。見るたびには変わらない。
  - 本人が服を買う（`Wardrobe.step`）: 一日にまれに（服が好きなら 2 倍）、自分のお金の 3 割までで持っていない服を買う。
  - 服の一覧・ポーズの一覧は全体で 1 つ（`data/outfits.json` / `data/poses.json`）。既定に後から増えた項目は一度だけ足し、消したものは戻さない（`store.sync_list_defaults`。足したことのある id は `<名前>.seen`）。
- **ポーズを取って・見せて**（`core/posing.py`。コマンド `_pose` / `_show`、`POST /api/act {action, pose}`）: 一覧 `data/poses.json`（`type`: pose / show・`bold` 0〜3・`outside_ok`・`pos`（見せては「〜 focus」）・`neg`）。大人のキャラだけ（定義の `age` に 18 未満が入っている人には出さない。未入力は大人として扱う。判定は年齢の欄だけで、外見のタグ・性格・プロンプトからは推し量らない。既定のひなは 20、出会いで作る人は 20〜34、設定から追加した人は 20）。受け入れは `Wardrobe.accept`（しつこさは `pose_asks`）で、反応の条件は `pose_feel` / `pose_bold` / `pose`。受けてくれたらその回の画像のプロンプトがそのポーズ・部位になる。効き目は `bonds.realize` を通す。
  - 相手から（`Posing.live`）: 二人きり・あなたが画面の前にいるとき、1 時間に 0.12 × その気（`eagerness`: ドキドキ・好感度・機嫌・恥じらい. 0〜1.5）。6 割はその場でポーズを取る・見せる（画像あり）、4 割は「見せてあげようか？」と持ちかける。選ぶものは自分から出せる大胆さ（`comfort` + ドキドキ 50 以上で 1）まで、覚えた好みで重み 1 + 0.6 × 好み。返事は働きかけの欄（`state_view.approaches` の `_pose`）で、`POST /api/approach {answer: "reply", choice}`。
  - 感想（見せてくれたとき）: 褒める・照れる・もっと見たい・からかう・止める。`Posing.judge`（恥じらいの強い人は褒める・照れるを、大胆な人はもっと見たい・からかうを好む。機嫌・好感度・揺らぎ ±15. good の 1 割は neutral）。
  - 対価（持ちかけ）: 求める割合 0.12 + 相手の懐（5,000 円未満 0.25 / 15,000 円未満 0.1）− 好感度 − 性格の `money`（2〜60%）。6 割はお金（(800 + 1,200 × 大胆さ) × 0.7〜1.4、懐が寂しいと 1.5 倍）、4 割は家事の肩代わり（あなたの体力 −10・家が片付く）。断ると、対価つきなら少し、ただの持ちかけは性格しだいでがっかり。
  - 好みの学習（キャラの状態 `prefs`: `pose:<id>` / `show:<id>` / `outfit:<id>`。−10〜10）: 頼んだ・着せた +1、持ちかけを受けた +1、感想 褒める +1.5・もっと見たい +2.5・照れる / からかう +0.5・止める −3。相手から選ぶもの・本人の服選び（重み × (1 + 0.15 × 好み)）が寄る。
  - 移行: 以前のキャラごとの `wardrobe` は起動時に服の一覧へ移し（中身が同じものは 1 つに。id がぶつかれば新しい id）、元のキャラの持っている服にする（自動バックアップ）。
- 見る系のコマンドは5つあります。それぞれ画像の構図が違います。
  - 様子を見る（今していることごとに描写が変わる）
  - 顔をのぞきこむ（アップ）
  - こっそり見守る（こちらに気づいていない姿）
  - 全身を眺める（服装が分かる全身）
  - 寝顔を見る

### お金

あなたとキャラが、それぞれ所持金を持ちます。画面に出るのはあなたの所持金だけで、相手の所持金は（離れていても同居していても）出さない。分かるのは貸し借りの額・生活費の分け方の取り決め・相手が口にしたことだけで、お金に困っているかはおねだり・会話・部屋の様子（`places.home_glimpse`）からにじむ（`life.view` に `her_money` を含めない。条件式の `her_money` は使える）。

- **増え方**
  - あなた:
    - 仕事: 「仕事に行ってくる」と告げて実際に離れ、戻ったときに給料の出る時間 × 時給 × 仕事スキルが入る（画面を開いている間だけ。閉じたら最後の心拍まで）。出られるのは 6〜21時（体力20以上）、給料は 6〜23時の分だけ・1日合計9時間まで。15分未満は稼ぎなし。ここ3日で働きすぎると、寂しがっているキャラが「仕事ばっかり」と機嫌を損ねる
    - あなたの体力: 仕事（1時間で9）・内職（10）で減り、時間で戻る（1時間で5、寝ていると12）。減っていると構っても効きが悪い
    - 内職: パズル（マインスイーパ・数独・ピクロス・スリザーリンク・15パズル・2048・タイピング・フリーセル・スパイダーソリティア・クロンダイク。易・中・難）を解いて稼ぐ（`core/puzzles.py`）。トランプの一人遊びは `core/solitaire.py`（カードは 0〜51、画面へは "AS" の形）。フリーセル: 難しさはセルの数（`FC_CELLS`: 易 4・中 3・難 2。目安 6・8・11 分）。配りは解く仕組み `fc_solve`（一枚ずつの手だけで、安全な組札上げは自動。崩れの少ない局面から調べる最良優先。局面の上限 `FC_BUDGET` 25,000）で解けると確かめたものだけ出す（確かめきれなかった配りは捨てて配り直す。難は確かめに数秒かかることがあるので、中・難は一つ裏で作っておく `puzzles._so_prepared`）。手は - **常備数**（`items.stock`、`/api/items/stock`）: 持ち物の数え方（食材は回分）で決め、使って減って（`Items.add` の負の数）下回ると、足りない分を買う単位に切り上げて買うものリストへ（`Items.restock`。リストにすでにその数以上あれば何もしない）。手で消したリストは次に減るまで戻さない。
- **借金のあいだ**（`life.in_debt`: `debt` か `loans` が残っている）: 買い物では必需品（`items.ESSENTIAL_KINDS` = 食材・洗剤）しか買わず、買うものリストのほかの品は見送る（衝動買いもしない）。スキルの伸びは抑えない。借金には月はじめに利息（`economy.debt_interest_per_month`、既定 1.5%。知り合いに借りた分にはつかない）。
- **返す**（`life.repay` / `POST /api/money/repay {to: "debt" | <id>, amount}`）: 財布の「返す」から、手元のお金の範囲で。借りた相手に返すと喜ばれ信頼が少し戻る（`bonds.realize` を通すので揺らぐ。返すのが遅れていたら半分ほど）。全部返すと「返してくれない」理由は解決。そばにいればその場で（`chat.repaid` のセリフを記録に）、離れていれば振り込みで、返事はメッセージの時間差で届く。
- **返済の遅れ**（`life.money_concern`、相手の日付が変わるたび）: 事情を知っている相手（お金を貸した人・借金を知っている同居相手）は、猶予（`economy.loan_grace_days`、既定 14 日）を過ぎると、ときどき（`money_concern_per_day`、既定 0.25）気にする。心配するか不信感を持つかは慎重さ（`caution`）・好感度・信頼・遅れの長さしだい。不信感は口に出さないこともある（機嫌の理由に「まだ聞いていない」で残る）。口に出せば、一緒にいればその場で、離れていればメッセージで（`chat.money_worry` / `chat.money_distrust`）。まだ返していない相手は、また頼んでも貸してくれにくい。
  - おまかせでは、好感度やキャラの懐具合でおごってくれることもあります。
- 金額（日給・生活費・時給・内職の基本額・ニュースの出やすさと当たりやすさ）と銘柄（`economy.assets`）は、**設定 → 時間帯・数値 → お金・出来事** で変えられます。

### キャラの出来事と機嫌の理由

機嫌は、こちらの行動だけで決まりません。

- 時間の経過で、キャラにもときどき出来事が起きます（`data/worlds/<id>/events.json`、**設定 → キャラの出来事** で編集）。
  - 例: 友だちから連絡が来た、講義で褒められた、ケンカした、予定が雨で流れた、バイト代、衝動買い、お金のピンチ
  - 出来事は機嫌やストレスを動かし、「機嫌の理由」として記録されます。
  - お金に困るとおねだりが、余裕があるとプレゼントやおごりの申し出が、画面の「お願い」欄に出ます。
- **機嫌の理由**: 良い理由も悪い理由も記録し、ステータス画面に出します。あなたの行動（褒められた、からかわれた、など）も理由になります。
  - まだ聞いていない出来事は「？」と表示され、名前の横に「💭何かあったみたい」と出ます。
- **会話のコマンド**
  - 何かあった？: 理由を聞く。好感度が低いと、はぐらかされる
  - 謝る: あなたのせいなら許してくれる（許し方に幅: すぐ・半分だけ・態度で・受け付けない・今さら？。続けて謝ると「もういいって」）。理由も知らずに謝ると「何に謝ってるんですか？」と、かえって不機嫌になる
  - 相談にのる: 理由を聞いてからだとよく効く。あなたが原因なのにのろうとすると逆効果
  - そっとしておく: 一人になりたいときは効く。寂しいときは逆効果
- **留守のあと**: 日給・生活費・株の値動き・出来事は、離れていた間の分もまとめて進みます。
  - 「おかえり」のとき、留守中に起きたことを話してくれます。
  - 1週間以上空けると、ずいぶん寂しがります（好感度が下がる）。

### 「あなた」中心の画面（何を・誰と）

画面は「選んだキャラ 1 人」ではなく「あなた」が中心で、何を・誰と（あるいは一人で）するかで組み立てている。

- **いまそばにいる人**（`bonds.company()`）: 外で会っている人（`with.mode = meet`）・相手の家に来ている（`visit`）・招いた人（`guest`）と, 家にいる同居相手。同居相手がそばにいるのは, あなたも相手も家にいるときだけ（`bonds.mode` / `home_together`: あなたが外出・仕事中（在席 `out` / `work`）か, 相手のいまの場面が `away`（大学など）なら離れている = 連絡はスマホで時間差）。招いた人がいて同居相手も家にいれば, そばにいるのは二人。条件キー `company`（そばにいる人数）。
- **そばにいる効果は二人きりのときだけ**（`engine._step`）: 在席の効果（`presence.effects`）は, そばにいる人それぞれにかかるが, あなたとその人の二人きりでなければ寂しさを紛らす分（`loneliness` のマイナス）はかからない（`bonds.alone_with`）。
- **「誰かと」の相手**（`App.target(cid)`）: そばにいる人の中から選ぶ（画面のプルダウン, `POST /api/target {id}`。選んだ相手はワールドごとの `local.json` の `active_character` に覚える）。誰もそばにいなければ None。`GET /api/state?character=` で相手を指定。いまは一人に向けた行動だけ（二人同時に向けた行動や, ほかの人が見ている反応はまだない）。
- **`state_view`**: あなたのこと（`you` = `life.player_view`: お金・株・借金・体力・スキル, `presence` `solo` `home` `items` `outdoor` `side_job` `contacts` `appoints` など）, そばにいる人（`company`）, 相手（`target`, `with` = `App.person_view(cid)`: 場面・状態・できること `available`・着せ替え・ゲーム・相手とのお金 `life` = `life.partner_view`）, 話しかけ・メッセージの返事待ち（`approaches`: 誰から）, 関係性（`people` = `App.people_view`）, あなたの時系列（`log` = `App.timeline`）。`person_view(cid)` は離れている人にも使える（テスト・スマホの「できること」）。
- **キャラのログに残すのは, その人がその場にいて関わった出来事だけ**: その場にいない相手に向けた, あなた一人の行動のコマンド（仕事に行く・仕事から帰る・出かける・戻る など）は, `act` の中で相手のログには書かず, あなたの記録へ（`my_entry`）。以前の「選んでいるキャラ」の作りで, 離れている相手のログに書かれていた「（仕事から帰ってきた。…）」などは, 起動時にあなたの記録へ移す（`App._migrate_my_entries`。一度だけ・自動バックアップ。外で会っていた相手と「別れて」出かけたところは, その人のログに残す）。
- **一人の行動**（戻る・仕事から帰る・内職・株）: そばに誰もいなければ, 誰にも告げずに結果だけ（`App.my_entry` → 一人の時間の記録 `mylog.json` に `id` `icon` `name` `money` `skill` つきで残す）。そばに誰かいれば, いままでどおりその人が反応する（`_back` / `work` / `side_job` / `invest_*`）。内職の休憩はあなたの記録（`player.json` の `side_job_t`. 以前のキャラの状態の `cooldowns.side_job` も見る）。
- **あなたの 1 本の時系列**（`App.timeline(who)`, `GET /api/log?who=`）: 各キャラのログ（`who` / `who_name` つき）と一人の時間の記録を時刻順に。`who` = キャラの id ならその人との記録だけ, `me` なら一人の時間だけ。離れていたときの記録には `apart: true`（画面では相手の場面を出さない）。ギャラリー・アルバムも全員分。
- **関係性**（`people_view`）: 知っている人全員の間柄・最後に会った / 連絡した（状態の `last_met` / `last_contact`。`bonds.met`）・あなたが知っていること（状態の `known`: `like` / `dislike` = プレゼントを渡してみて分かった（`give_item`）・相手の部屋で見た（`places.home_glimpse`）, `heard` = 本人から話してもらった出来事（機嫌の理由のうち `told` になったもの。`bonds.remember`））・あなたが借りている額・生活費の分け方。見た目の印象は, そばにいる人だけ（画面の表示設定に従う）。
- **相手の予定の知り方**（`core/knowsched.py`）: 遊んでいる画面では相手の予定は分からない。聞いた・見かけた予定だけが「知っていること」（状態の `known`, kind `schedule`。聞いたときの予定の中身の目印 `key` つき）になり, 関係性の `sched` に出る（`view`: いまの予定に同じものがなければ `stale` =「もう違うかも」, 60 日より前なら `old`）。対象は出かけている・手が離せない・勤め先のある予定（寝る・食事・身支度・帰り道などは除く。`notable`）。きっかけ: 話のついで（`engine.SCHED_TALK` のコマンドのあと `from_talk`。6% + 会話 8% + 気配り 6% + 好感度で少し）・人づて（`_secondhand`: 相手が `relations` で知っている人の予定, 3〜7%）・職場（予定の `workplace` = 行き先の id。外出中の心拍で `at_workplace`: その時間にその行き先にいれば「店員として働いていた」。外出ごとに一人一度, 一緒にいる人は除く。会えた扱い `bonds.met`）・メッセージ（離れている相手からのメッセージのあと `from_message`: 今日済んだ予定を 30% で, 一日に一度。トークに `sys` の一行）。新しいセリフの場面はなし（ナレーション）。既定のひなには土曜 10:00〜14:00 の本屋のバイトを足した。設定の生活スケジュールは作る人の画面として残し, 開く前に一度確かめる（`SE.schedOk`）。
- **相手の所持金は出さない**: 離れていても同居していても。分かるのは貸し借り・取り決め・相手が口にしたことだけ。
- **一人のとき, ステージには何も出さない**: 画像は常にキャラクターのものだけ（場所だけの画像は作らない）。📷 今の様子を撮る・プロンプトの組み立ても, そばにいる人がいるときだけ（`snapshot` / `prompt_preview`）。
- 画面: 右の欄のタブは「一人で」（一人の行動・📱 スマホ・あなたの体力とスキル）/「〇〇と・誰かと」（そばにいる人とのコマンド・着せ替え・ゲーム・ようす・お金のこと。誰もいなければ出さない）/「お金」（あなたのお金）/「持ち物」/「関係性」/「ログ」（人で絞り込み）。トップバーは「🏠 暮らし」と「👥 いまそばにいる人（いなければ いまは一人）」（以前のキャラ切替はなくした）。スマホ（`📱`）はトーク一覧から相手を選び, メッセージの種類か電話・約束・「家に行ってもいい？」など（`chat.thread.actions` = `chat.phone_actions`）。

### そばにいる・離れる（在席）と、キャラからの働きかけ

画面を開いているあいだ、あなたは家（や出先）にいて、そばにいる人と過ごしていることになります（画面が 30 秒ごとに心拍を送る）。

| 状態 | なるとき | キャラへの影響 |
|---|---|---|
| そばにいる | 画面を開いて操作している | 寂しさがいちばん紛れる（二人きりのときだけ） |
| のんびり | 10分以上なにも操作していない | 少し紛れる。キャラから話しかけてきやすい |
| 作業中 | 「ちょっと作業するね」と告げた | キャラは遠慮して話しかけてこない（とても寂しければ来る） |
| 外出・仕事・就寝・離れる | 「あなたの予定」のコマンドで告げた（そばに誰もいなければ一人で） | 就寝・離れるは画面を閉じてもよい。外出・仕事は画面を開いている間だけで、閉じたら切り上げて家に帰る（出会いもその間だけ。閉じたあとはオフライン時の過ごし方どおり）。「戻る」で戻る |
| いない | 何も言わずに画面を閉じた | 告げたときより寂しさが早く増える。戻ると空けた時間ぶん機嫌・信頼が下がり（1日以上なら好感度も）、1時間以上で「急にいなくなるから…」と言われる |

- **キャラからの働きかけ**（`data/worlds/<id>/approaches.json`、**設定 → キャラからの働きかけ**）: そばにいる・のんびり・作業中のとき、寂しさ・退屈・好感度に応じて、キャラのほうから話しかけてくる（おしゃべり、お茶、もたれかかる、ゲームや散歩のお誘い、まだ怒っている、聞いてほしい出来事 など）。
  - 「応じる」「あとで」で答える。放っておくと待ち時間のあとで「返事がなかった」になり、寂しいときほど機嫌が下がる（作業中・不在なら軽い）。
- **性格ごとの傾向**: 性格プリセットの `traits` で、パラメータの動き方が性格ごとに違う（`rate` 基本変化の倍率、`drift` 自然回帰の目標の加算、`drift_speed` 戻る速さ、`gain` / `hurt` うれしい方向・つらい方向の効き目の倍率、`approach` 話しかけてくる多さ、`absence` 黙って離れられたときの堪え方）。例: 甘えたがりは寂しさが 1.6 倍の速さで増え、黙っていなくなると強く堪える。クールは機嫌の振れ幅が小さい。
- **あなたのスキル**: 会話・スキンシップ・料理・仕事。使うほど伸び、対応するコマンドの効き目（仕事は給料）が 0.6〜1.4 倍になる。数か月かけて少しずつ上達する（`life.train`: 経験の `SKILL_RATE` 倍だけ身につき、上がるほど・同じ日にたくさんやるほど伸びにくい。得意・不得意 `aptitude` はワールドごとに一度決まり、その日の調子で揺れ、伸びない日もある）。スキルは 9 つ: 会話 `talk`・スキンシップ `touch`・料理 `cook`・仕事 `work` と、家事 `house`・気配り `care`・身だしなみ `groom`・やりくり `budget`、文章 `write`（副業の文章の仕事の依頼の来やすさと出来ばえ。研鑽と文章の仕事で伸びる）（家事〜やりくりの 4 つは `life.skill_soft`（0〜1）で控えめに効かせる: 家事 = 片付けの量 ×0.85〜1.2（`solo.result` の chores）、気配り = 見た目の印象のずれ ×1〜0.5（画面の `lookWord`。`state_view.you.care`）・まだ聞いていない出来事に気づく割合 55〜95%（`life._noticed`。出来事ごとに決まる）、身だしなみ = 出先の人と段階が進む確率 ×0.9〜1.1（`street.resolve`）、やりくり = 家計簿の書き漏らし ×1〜0.4・丸め / まとめが 1 日遅い（50 以上）・見積もりの幅 ×1〜0.7（`kakeibo`）、買い物の値段の上振れが小さい・衝動買い ×1〜0.5・品切れのとき代わりの品 15〜60%（`items.shop` / `_substitute`）。伸ばし方: 家事 = 家事・一緒に掃除、気配り = `engine.CARE_ACTIONS`、身だしなみ = 出かけるたびに少し・自分の服 `clothes` を買う、やりくり = 家計簿・買い物。どれも研鑽（本 `items.PRACTICE_BOOK`）。株のニュースの読みには効かせない（ニュースの当たり外れは誰にも読めないのが現実で、スキルで当たりやすくするのは補正になるため）。以前のデータには初期値 10 で補う（`life.player_state`）。使わないと鈍る（`life.rust`: 最後に使ってから `RUST_AFTER_DAYS`（10 日）を過ぎると、日付が変わるたびに「最高値の半分」との差の `RUST_RATE`（2%）ずつ、使わない日が 10 日続くまでは緩く下がる。最高値 `skill_peak` の `RUST_FLOOR`（半分）より下がらない。最後に使った時刻 `skill_used`。鈍ったぶんは `RELEARN`（2.5 倍）で戻る。画面には「（鈍り）」）。料理が下手だと焦がす、会話が下手だと沈黙する、などの反応もある（条件キー `sk_cook` `roll` など）。
- **お出かけ中**は、料理・お風呂・掃除・映画など「家でだけできる」（`home_only`）コマンドは出ない。

### ワールド（セーブ単位）

キャラクターの定義は全体で 1 つ（`data/characters/`。どのワールドで編集しても全ワールドに反映）。各ワールド（`data/worlds/<id>/`）には、顔ぶれ（`cast.json`）と各キャラの個体（状態・ログ・間柄・関係）、あなたのお金／株／スキル／在席、コマンド・パラメータ・世界設定・出来事・働きかけ・ミニゲームの定義がある。ワールドAのひなとワールドBのひなは、同じ定義でも過ごした日々と関係は別。削除は定義の抹消で、どこかのワールドに現れているキャラは削除できない（`delete_character`）。以前の形式（ワールドごとの `characters/`、`registry/characters/`）は起動時に統合し、同じ id で中身の違うものは別のキャラとして id を振り直して記録の参照も付け替える（`store.migrate_characters`。元のフォルダは `.migrated` として残す）。

- **設定 → データ** で作成（登録済みのキャラから・間柄はくじ／今のワールドを複製）・切り替え・名前変更・削除。2 つ以上あると上のバーに切り替えが出る。
- **セーブの書き出し・読み込み**（`core/transfer.py`）: ワールド 1 つ（`data/worlds/<id>/` そのまま）と、そこに現れているキャラの定義・自作の性格プリセットを 1 つの zip に（`GET /api/world/export?id=&images=1`）。画像（記録・顔のアイコンから参照されているものと索引）を含めるかは選べる。読み込み（`POST /api/world/import {data: base64}`）はいつも新しいワールドとして足し、いまのワールド・定義・画像は上書きしない: 同じ id で同じ中身（両方にある項目が同じ）の定義はこちらのものを使い、中身が違えば別の人として新しい id を振って、読み込んだワールドの記録の id を付け替える。性格プリセット・画像はこちらに無いものだけ足す。形式の移行は開いたときにいつもどおり。
- 全ワールド共通: `data/settings.json`（ComfyUI・LLM・表示・あなたの名前）、`data/personas/`、`data/workflow.json`、`data/images/`（画像と索引。同じプロンプトの画像はワールドをまたいで再利用）。
- 以前の版の `data/` 直下のキャラ・状態・ログ・定義類は、初回起動時に「最初のワールド」（`data/worlds/w1/`）へ移す。
- **キャラ同士の関係**（`relations.json`）: 同じワールドのキャラについて、a→b の向きごとに「知っているか・関係（自由記述）・好感度 0〜100」。**設定 → キャラクター** で編集し、知っている相手は LLM のセリフ生成に渡す。

### あなたとの間柄（連絡先 → 家に行ける仲 → 同居）

`core/bonds.py`。新しく作ったワールドでは誰とも暮らしていない。キャラの定義全員（`data/characters/`）から、くじで「連絡先」「知り合い（known: 連絡・誘い不可、偶然会って話すと連絡先を交換することがある。確率は `bonds.exchange_chance`: あなたの会話スキル・相手の機嫌と好感度・性格の caution で 5〜85%）」「まだ知らない（そのワールドには入らず、出会いの候補）」を決める（`encounters.start_contact` / `start_known`、最低一人は連絡先。worlds.json の `start_bonds`）。状態・ログ・関係は一から（最初のワールドは選んでいたキャラと同居）。間柄といまの居場所は `player.json` の `bonds` / `with`。

- 一緒にいない相手には「連絡」「会う」「あなたの予定」だけ。同居していない相手とのお出かけ・訪問・招待は、約束してから（`appoint.needs`。下の「約束」）。個別にはコマンドの `"apart": true/false`。条件キー `stage` `apart` `with_mode` `living_other` `rivals` `rivals_known`。
- 誘いに応じてくれたら外で会う（お出かけの一時シーンが終われば別れる）。「家に遊びに行く」は `visit_hours` 時間で帰る。
- コマンドの `"bond"`: `to_visit`（家に行ってもいい？）/ `to_live`（一緒に住まない？。同居は一人だけ）/ `end_live` / `visit_start` / `visit_end`。断る反応（置き換え）なら変わらない。
- 一緒にいない相手からの働きかけは、`approaches.json` の `"apart": true` のものだけ（📱 メッセージ、画像なし。一緒のときは逆に出ない）。来やすさは `presence.approach_apart_rate_per_hour` × 寂しさ・好感度・機嫌。あなたが外出中・仕事中でも届く（出かけている同居相手からも）。連絡先を知っている離れた相手なら誰からでも届き、そばにいる人は誰でも話しかけてくる（`state_view.approaches`）。メッセージを送れば、それが返事になる。
- **メッセージへの返事は選択肢**（`core/msgreply.py`）: `msgreply.OPTIONS`（メッセージごとに 3〜4 つ: cheerful 明るく乗る / expand 話を広げる / worry 心配する / tease からかう / curt 素っ気なく）。`POST /api/approach {answer: "reply", choice, character}`（`choice` なしの accept は先頭の選択肢）→ `presence._reply`。受け取り方 `msgreply.judge`（good / neutral / bad）= 種類の基本 + 内容との合い方 `FIT` + 性格の好み `TASTE` + 機嫌・好感度・会話スキル + 揺らぎ ±15（からかいは好感度 60 からの差 × 0.4、素っ気ないは寂しさ 40 からの差 × 0.2 だけ下がる。good でも 1 割は neutral）。good は働きかけの accept の効果、neutral は寂しさ −3、bad は機嫌 −4・好感度 −1・信頼 −1 と機嫌の理由。どれも `bonds.realize` を通す。相手の返しは `msgr.<種類>.<結果>`、もう一言は `msgr.more.<結果>`（good 55%・neutral 30%・bad 45%）で、性格プリセットで差し替えられる（18 場面）。
- **返事をしないまま時間切れ**（メッセージ. `presence._expire`）: 待つ時間は既定 90 分（`wait_minutes`）。効果は ignore の効果 × 0.6 × 性格の `absence` × 既読なら 1.4・未読なら 0.7（トークの `seen_t` がメッセージより後なら既読）× 急ぎの度合い `urgency`（既定: 会いたい 1.4・何してる？ 1.0・今日の出来事 0.8）× (0.5 + 寂しさ/100)。既読のまま放っておくとトークに「既読のまま返事をしなかった」と残り、機嫌の理由は「既読のまま放っておかれた」。
- 離れている相手も、本人は自分の予定（スケジュール）どおりに過ごしている。条件式の `away` は「あなたから見てそばにいない」も含むが、本人のパラメータの動き・出来事は本人の過ごし方で決まる（`App.context(..., view=False)`。家にいれば外出中の体の動きにならない）。見え方は今までどおり（離れている相手の様子は既定で伏せる）。
- メッセージは画像なし。`"selfie": true` のコマンドは、機嫌・好感度・ドキドキが高いほど自撮りが添えられる（上限 35%）。
- 嫉妬: あなたと深い仲のキャラは、時間経過であなたとほかの人との深い仲に気づく（同居だと気づきやすい。性格の `jealousy` 倍率）。機嫌の理由に残り、その相手への好感度も下がる。

### 一人の時間（何を、誰と）

- 告げる形のコマンド（`go_*`）は、そばに誰かいるとき（`solo.near(cid)` = 「誰かと」の相手）だけ。誰もいなければ、告げる相手なしの「仕事に行く・寝る」（`solo.PLAIN`。「席を外す」はそばにいる相手に告げて離れるためのものなので、そばに誰かいるときだけ。「作業する」は同居相手に作業中と伝えるためのものなので、同居しているときだけ。外出は一人の時間の「外出」（行き先を選ぶ）から。条件は go_* と同じで、あなた一人の条件式の値 `App.you_context()` で判定）。トップバーの 🏠 に「一人暮らし／〇〇と同居」, 👥 に「いまは一人／そばにいる人」。
- スマホ: 離れている相手へのメッセージ・電話は、相手の状況に関係なく送れる/かけられる（コマンドの `apart_when`）。トップバー・「一人で」・外出中・仕事中のオーバーレイの「📱 スマホを見る」（`state_view.contacts`）から、誰かといるときも。一人の時間はスマホでは終わらない。電話（`"phone": true`）は相手が寝ている・手が離せない・気分しだいで出ず（`_call_missed`）、折り返しが `msg_pending` の `callback` でメッセージとして届くことも。出たら `peek_until` の間、相手の場面だけ見せる。連絡回数（状態の `contacts`）が許容（2 + 2 × 性格の approach、家に行ける仲 +2・同居 +4）を超えると条件キー `too_often`。仕事中の連絡（`presence.work_contacts`）が 3 回以上で給料が減り、5 回以上で注意。
- 離れている相手へのメッセージ（`message`、またはコマンドの `"reply_later": true`）は送るだけ。返信の予定は状態の `msg_pending`（数分〜40分、機嫌・好感度が低いと遅く、来ないことも）。`deliver_due()`（state_view のたび）で、寝ている・手が離せない相手は落ち着くまで延ばし、届いたら返信として記録（効果・交流もこのとき）。24 時間で消える。相手があなたに送った・返した直後はしばらくスマホを見ている（`phone_until`. 2〜10 分 × 性格の `approach`）。その間に送ると, 機嫌・好感度・続いた回数（`phone_turns`）・連絡しすぎ・性格しだいで 10〜90 秒で返ってくることがある（`_still_on_phone`. 必ずではなく, 外れたらスマホを置いて以後は時間差）。寝ている・手が離せないときはすぐには返さない。トークを開いている間は返信待ちなら 8 秒ごとに見直す（`/api/chats` も `deliver_due` する）。
- 会話のノリ（`core/nori.py`、状態の `nori` = {v: 0〜100, t, turns}）: 相手から送ってきた（`presence.fire`。暇で送る `msg_chat` は上乗せ大）・あなたのメッセージを読んだときに始まり（退屈・寂しさ・機嫌・好感度・性格の `approach`・夜・ストレス・揺らぎ）、返事の効き目（`after_reply` は機嫌の動き、`after_choice` は good/neutral/bad）で上下し、1 往復ごとに疲れて下がる。会話中は `_still_on_phone` の確率・`picked_up_phone` の長さ・時間差の遅れ・もう一言の割合に効く。2 往復以上して 20 を下回ると相手から切り上げる（`chat.close_night` / `close_busy` / `close_cold`。スマホを置く）。30 分やりとりが無ければ終わり（`level` は None で、以前どおりの式）。
- 献身度・依存度（`core/attach.py`、状態の `attach` = {devotion, dependence, ledger, day}。0〜100、画面には出さない。条件式でも使える）: 初めの値は、はじめて使うとき（以前のセーブなら起動後）に性格の傾向（`approach` / `absence` / 寂しさの増えやすさ / `carer`）と今の好感度・信頼・間柄から。動きやすさは性格しだい（`Attach.speed`）、一日に動く幅は `DAY_CAP` まで、揺らぎあり。動き: 尽くした帳簿（`give`。相手が払う・おごる・看病・予定を合わせる ↔ あなたの贈り物・手伝い・約束を守る・返済・相談）を日ごとに見て、お互いさまなら献身度が上がり、尽くさせてばかりだと下がる（依存度 65 以上なら半分の確率で逆に上がる＝共依存）。依存度は、会えて寂しさが紛れる・送ったメッセージに返事が来ると上がり、長く会わなくても平気・ほかに親しい相手・傷つけられることが続く・返事が来ないと下がる。効き: 依存度 → 相手から構いに来る・送ってくる頻度、連絡の多さの余裕（`tolerance`。低くても少し減るだけ）、黙っていなくなったときの重さ、嫉妬、寂しさの増え方、会話のノリの始まり。献身度 → 約束の受けやすさ・予定を動かして合わせる（`rearranged`）・すっぽかし・遅刻・仮病のキャンセル・別の日時を返す、おまかせの支払い、おねがいの種類（低いと貸して・買って、高いとごちそう・プレゼント）、頼まれごとの頻度。誠実さ（見せる好意と本心のずれ）は保留で、`hold/sincerity` ブランチに残してある（以前のセーブの値は読み込み時に捨てる）。ヒモ・束縛などの型はこの組み合わせと今ある状態から生まれる例で、キャラ作成では扱わない。
- 家事: 一人の家事は `solo.start("chores", skill=<mess|dishes|laundry|trash>)` で一つだけ（無ければ全部）。`Home.clean(power, parts, now)`: 洗濯は雨・雪（`Home.wet`）なら 6 割、ゴミはゴミの日の朝 5:00〜8:30（`trash_days` = ワールドごとに週 2 日、`trash_ok`）でなければ 2 割（まとめるだけ）。オフラインの家事も同じ。カレンダーにゴミの日。同居の分担（`core/chores.py`、同居相手の状態の `chores_share` / `slack` / `chores_plan`）: `POST /api/chores/share {part, who}`（相手の担当にするときだけ、献身度・`neat`・`carer`・機嫌・さぼり癖で引き受けるか）。日付が替わると相手が今日やる時刻を決め（`daily`）、`tick` でやるかどうか（やれば `attach.give(her)`、そばにいれば「やっておいた」）。相手の担当が 60 以上で二人とも家にいると、さぼりの知らせ（`pending` → `POST /api/chores/respond {choice}`: overlook = 自分で片付け・体力・さぼり癖 +、ask = すぐ / あとで / 渋々、scold = 改まる / 反発（理由と `chores_fight`）、joke = 好感度しだい）。あなたの担当が 70 以上なら、相手が代わりにやる（`give(her)`）か責める（理由）。一人で相手の担当を片付けたら `give(me)`。以前のセーブ: 分担は全部「気づいた方」、さぼり癖なしから。
- 資格（`core/quals.py`、`player.json` の `quals` = {apps, study, have}）: `QUALS` の 6 つ。試験は各月の第 2 日曜 10〜13 時（`exam_day`）、申し込みは 30 日前まで（`next_exam`。`POST /api/quals/apply`、受験料は家計簿に）。勉強は研鑽の `skill: "qual:<id>"`（`Quals.study`。勉強時間と、要るスキルの最初のものが少し伸びる）。受かる確率 `pass_chance` = ロジスティック（1.6 + 4 ×（スキル平均 / 目安 − 1）+ 3 ×（勉強時間 / 目安 − 1）− 疲れ・体調、上限 0.92）。日付が替わるとき（`earn.daily` → `Quals.daily`）に、試験の日なら受ける（体調が寝込む程度なら欠席）、2 週間後に合否（落ちたら勉強時間の 3 割を持ち越す）。合否は一人の時間の記録・家計簿の知らせ・話題（`qual`）に。効き目: 本業の見直しで上がる確率 + `raise`、上限 `cap`（2.0 → 2.3）、資格手当 `allow`（その月 40 時間以上）。アルバイトの面接 + `job_pass`、時給 + `job_wage`。副業の依頼 × `gig_p`、単価 × (1 + `gig_rate`)。家計簿の覚え + `kakeibo`。カレンダーに試験の日と合否が届く日。
- 誕生日・記念日（`core/anniv.py`）: キャラの誕生日は定義の `birthday`（"MM-DD"。無ければ `bday:<id>` の揺らぎで固定。2/29 は平年 2/28）。知るのは「誕生日を聞く」（会って `POST /api/anniv/say {kind: ask_bday}`、メッセージは種類 `ask_bday`。好感度 20 未満か、あなたのせいで機嫌 25 未満のときだけ教えない）か、1 か月前ごろに家に行ける仲以上・好感度 55 以上で半々に自分から（`bday_hint`）。知ったら `bday_known` と「知っていること」。記念日は `bonds` の `hist`（`set_stage` で段階ごとに残す）: 一周年（期待 ×0.7）と、月ごと（1〜11 か月。`MONTHLY` の性格か依存度 70 以上。期待 ×0.35）。期待 `care` = 性格 `CARE` × 間柄（連絡先 0.3 / 家 0.6 / 同居 1.0）× 好感度 × 依存度。日付が替わるとき（`life.step` → `Anniv.daily`）に前の日を `_evaluate`: したこと（`mark`: おめでとう 0.4・会った 0.3・贈り物 0.3・外食 0.2）が期待の 6 割か 0.4 に届けば喜ぶ（`realize`）、期待 0.35 以上で届かなければがっかり（誕生日を教えていたら ×1.4、知らなかったら ×0.4）＋理由 `_anniv_forgot`、気にする人はたまに翌日「忘れてた？」（`bday_forgot`）。3 日以内のおめでとうは `congrats_late`（理由は解決）。メッセージのおめでとうは送った時刻で見る。相手から言ってくること（`anniv_her` / `bday_hint` / `your_bday` / `bday_forgot`）は `anniv_msgs` に時刻を決めて入れ、`tick` で届ける（そばにいれば記録、離れていればトーク）。あなたの誕生日は設定の `player.birthday`、伝えた相手（`knows_my_bday`）が、好感度・献身度・依存度しだいで当日に祝う。カレンダーのメモ（`POST /api/memo/add {date, text, yearly}` / `/api/memo/del`。`player.json` の `memos`）。レストランの予約（`reserve_full`: 金土の夜 0.55・ほかの夜 0.2〜0.3・休日の昼 0.2・平日の昼 0.05 × 祝日年末 1.4 × 何日前（当日 1.5〜1 週間以上 0.3）× 揺らぎ。`Appoint.propose` で、誘う前に分かる）。以前のセーブ: はじめて使うとき（`anniv_v1`）にログから記念日を拾う（出会った日 = 最初の記録、家に行ける・同居 = 受け入れられた `ask_visit` / `ask_live`、分からなければ無し）。使い始める前（`anniv_since`）の日では受け止めない。
- 話題（`core/topics.py`、`player.json` の `topics`、キャラの状態の `tastes`・`topic_tags`）: 一人の時間の結果（`solo.result` → `from_solo`。出かけた先・走った先）、誰かと出かけた・映画を観た（`act` → `from_act`。`with` 付きの思い出話）、本を読む・映画を観る（一人の行動 `read` / `movie`。`READ_H` / `MOVIE_H` 未満で切り上げると話題にならない。読むと小説を 1 冊使う）、仕事（2 時間以上でときどき）、噂（`rumor.hear` → `from_rumor`）。系統 `TAGS` は裏だけ。相手が乗るか（`judge`）: 好み `tastes`（性格の既定の好き・苦手 `LIKE_MAP` + キャラごとに固定の隠れた好み）・機嫌・ノリ・疲れ・鮮度・3 日以内の同じ系統（飽き）・思い出話・揺らぎ → hit / ok / bored（1 割は ok に寄せる）、同じ話は 8 割 again、噂は 35% known。会って（`POST /api/topic/tell` → コマンド `talk_topic` の反応 `topic_res`）とメッセージ（`POST /api/topic/send` → 種類 `topic`、返しは `talk_topic.<結果>` を 📱 で包む）。hit なら好きなものの覚え（`bonds.learn`）。21 日で消える。以前のセーブ: はじめて使うとき（`topics_v1`）に一人の時間の記録と相手との記録から直近 2 週間を拾う。隠れた好みもはじめて使うときに決まる。
- 献身度・依存度の新しい振る舞い（第 2 段階）: 依存度 75 以上で帰り際・送るとき・出かけるときに引き止める（`go_leave` / `leave_visit` / `see_off` / `go_out` の反応 `dependence>=75`。依存して自分優先 `devotion<40` なら出かける先を詮索）。依存度 80 以上で「離れたくない」（働きかけ `need_you`）。離れていてあなたが出かけている・仕事中に、依存して自分優先なら「今どこ？誰と？」（`msg_where`。返事は `msgreply.AP_REPLY` で `msgr.msg_where.<受け止め>`。正直に答えるのが効き、「なんで？」は外れやすい）。依存度 35 未満の相手に連絡が続くと（多すぎる手前、許容の 6 割から。一日一度・半々）、依存度 25 未満は距離を置き（`chat.want_space`）、献身度 65 以上は気づかう（`chat.own_time`。`Chat._space`）。予定があっても合わせてくれたときは `chat.appoint_rearranged`。自分優先なほど、約束の前日ごろに自分の都合で日を動かしたいと言ってくる（`_plan` の `move`、`chat.appoint_move_mine`、約束は誘われている状態に戻る）。2 週間以内にもお金を頼んでいれば、頼み方が `chat.req_money_again` に。
- 未読スルー: 好感度 35 未満で返さないと決まったとき、ときどき `msg_pending.unread`。期限が来ても読まず、3〜12 時間後に既読だけ付く（24 時間で流れれば付かない）。
- 連絡しすぎ（`bonds.ctx` の `too_often`）: 直近 24 時間にあなたから送った連絡の重みの合計（`bonds._contacts`。`st.contacts` は `[{t, w}]`、以前の記録の時刻だけのものは 1）が、我慢できる多さ（`bonds.tolerance`）を超えたら。重み（`bonds.contact_weight`。`engine._phoned` が記録）: 挨拶・スタンプ 0.5、電話 1.5、ほかは 1（`CONTACT_W`）。相手から返事・メッセージが来たあと（働きかけ中・最後の相手の発言があなたの最後の連絡より新しい）の 1 通は 0（会話）。返事待ちの間・既読のまま 6 時間のうちに続けて送ると × 1.5（追いメッセージ `FOLLOWUP_W`）。謝るメッセージは数えない。我慢できる多さ = 2 + 2 × `approach` + 間柄（家に行ける仲 +2・同居 +4）+ 直近 24 時間に相手から届いたメッセージの数（上限 4. `HER_BONUS_MAX`）、手が離せない（仕事中など）なら × 0.6、機嫌 65 以上 +1・寂しさ 60 以上 +1、その日の揺らぎ ±0.75（相手と日付で決まり、一日のうちは同じ）。目安（揺らぎを除く。返事のないまま送るふつうのメッセージで何通目に「多い」か）: クール（0.5）連絡先 3.0（3 通）・仕事中 1.8（2 通）、同居 7.0（6 通）／ はにかみ屋（1.0）連絡先 4.0（4 通）・同居 8.0（6 通）／ 甘えたがり（1.8）連絡先 5.6（5 通）・同居 9.6（7 通）。挨拶 2 回や会話の往復だけでは「多い」にならない。以前の記録にも遡る（`Manners.retro_contacts`。起動したとき・ワールドを切り替えたとき）: トークの記録からあなたの連絡を組み直し（`bonds.history_weights`: あなたの発言の種類と時刻・かけた電話・その前の相手の発言）、時刻だけの contacts を `{t, w, k}` に置き換える（突き合わせられない分は 1 回のまま）。この数え方になる前（相手ごとの `contacts_v2` の時刻より前）に返った「連絡多くない？」「謝ったばかりなのに」のうち、4 日のうち、または理由がまだ解決していないものを、その時点の記録（24 時間の重みの合計と、その時刻の我慢できる多さ）で判定し直し、「多い」にならなかったものは下がった機嫌・信頼・好感度を戻して理由を解決済みにする（文面は書き換えず、トークに「以前の「連絡が多い」を、今の数え方で受け止め直した：機嫌 +2…」を一度。`contacts_rejudged` で二重に当てず、お礼の当て直しで戻した `thanks_rejudged` は除く）。
- 離れている相手の様子（場面・ステータス・表情・機嫌の理由）は画面に出さない（本人から聞いた理由だけ）。設定 → 表示の「離れている相手の様子も見る」（`showApart`、このブラウザだけ）で表示。

`core/solo.py`。右の欄は「一人で」と「〇〇と / 誰かと」のタブ（相手の選択は「誰かと」のプルダウン. そばにいる人だけ）。

- 休む・家事・研鑽（スキルを選ぶ）・外出（行き先を選ぶ）は「始めて、戻るまで」。在席状態は家なら busy、外なら out（`presence.solo` に中身）。そばにいる相手がいれば既存の `go_busy` / `go_out` として声をかけ（`POST /api/solo/start {kind, skill, place, character}`）、いなければあなたの行動だけ記録。
- 戻ると（`come_back`）過ごした時間で結果: 休む = 体力回復が速い（`economy.stamina_recover_rest`）、家事 = 家が片付き（`home.chores`）、同居相手が気づけば機嫌が少し上がる（偶然、`home.notice_chores`）、研鑽 = スキル（揺らぎあり）、外出 = 行き先しだい（`places.solo_kind`: 公園・河川敷などは歩く、店は買い物（買うものリストの品）、カフェはお茶、水族館・遊園地は見て回る（入場料 `fee`）、外出中は偶然の出会いの判定（補正なし））。以前の「一人で散歩・一人で買い物・カフェで過ごす」（`walk` / `shopping` / `cafe`）は外出 + 行き先に読み替える（`solo.LEGACY`）。
- 外出の行き先に相手の家（家に行ける仲）を選ぶと、約束なしに訪ねる（`App.drop_in`）: 本人の予定で留守・寝ている・手が離せなければ出てこない。家にいれば、好感度・信頼・機嫌・慎重さ・時間帯（夜は迷惑）で迎えてくれるか決まる（`drop.yes` → 相手の家で過ごす `with.mode = visit` / `drop.no` → 機嫌の理由に残る）。迎えてもらえなければ、そのまま外（街）にいる。
- 日記: その日のログ（全キャラ + 一人の時間）から、LLM が有効なら LLM、無ければ定型で。一人の時間は `Solo.day_mine`: 始めたときの一行（`START_TEXT` / `PLAIN` の text）・計画の知らせ・`void` を除き, 同じ出来事（一方がもう一方の書き出し. 結果と「戻る」など）は長いほう一つ, 閉じていた間のまとめは `offline.parse_summary` で行動ごとにそれぞれの日へ。定型は 6 件まで（仕事の一行は残す）, `Solo._short` で文の切れ目（括弧の外の「。」）まで, 長ければ読点で「…」。直す前に定型で書いた日記は起動時に一度だけ書き直す（`rewrite_diaries`。`diary_fix_v1`。書いた時刻はそのまま, LLM の日記と, 一人の時間の記録（500 件まで）が足りない日はそのまま）。`mylog.json` / `diary.json`（ワールドごと）。API: `POST /api/solo/start {kind, skill}`、`POST /api/diary/write`、`GET /api/diary`。
- 新しいセリフは足していない（相手の反応は既存の「ちょっと作業するね」「ちょっと出かけてくる」のセリフ、一人のときはナレーション）。

### 現実的であること（このアプリの公理）

回数をこなせば仲が深まる、とはしない（`core/bonds.py` の `realize` / `readiness` / `gift_feel` / `cool_down`）。

- 好感度・信頼の上がり方は毎回揺らぎ、その日のうちに上がるほど鈍る（`bonds.gain_cap_*`）。機嫌が悪いと半減。コマンド・働きかけへの応答・ミニゲーム・偶然会ったとき、すべてに適用。
- 同じことを一日に何度も繰り返すと、うんざりされて逆効果になることがある。
- 同居していない相手とは、交流が `cool_after_days` 日途絶えると好感度・信頼が冷め、`drift_apart_days` 日で家に行ける仲が「連絡先」に戻る。交流した日は状態の `touch_days` / `last_touch`。
- 時間の経過だけで冷める分（寂しさが続く など、パラメータの規則による低下）も、好感度・信頼は `cool_floor` に近づくほど鈍り、そこで止まる（`engine.FLOORED`）。それより下がるのは、嫉妬などはっきりした出来事があったときだけ。
- 段階の提案は、条件キー `ready`（好感度・信頼・最近 14 日の交流日数 `met_14d`・ご無沙汰 `gap_d`・性格 `caution`・揺らぎ）で受けるかどうかが決まる。
- 贈り物は `gift_feel`、高価なプレゼント・お小遣いは `money_feel`（性格 `money`、仲の浅さ、最近の贈り物の数）で、喜ばれない・重いと断られることがある。物の効き目は性格 `gift` 倍率。コマンドの `"gift": "item" / "money"`。
- 偶然の出会いに偏りはない: 知らない人に会いやすくする補正も、誰かに必ず会わせる代わりもない。

### キャラを追加するとき

設定の「＋新規」（`POST /api/character/new {name, pos, persona_id, stage}`）で、このワールドでの間柄を選ぶ。`stage`: `contact`（連絡先）/ `known`（知り合い）/ `absent`（現れない。定義だけ作り、このワールドでは偶然の出会いの候補）/ `random`（新しいワールドと同じくじ）。同居はいきなりは選べない。定義の一覧は `boot.defs`（全ワールド共通。`here`・現れているワールド・出どころ `origin`: 既定／設定で追加（`origin`）／出会って登録（`met`、ワールドも）／以前のデータ）、定義の取得は `GET /api/character?id=`、`POST /api/character/define`（編集）・`/api/character/place {id, stage}`（このワールドに出す）・`/api/character/delete`（どこにも現れていない定義だけ）。

### 家の様子

`core/home.py`。あなたの家の状態（`W/home.json`: `mess` / `dishes` / `laundry` / `trash` 各 0〜100、`last_t`、`live_seen`）。

- たまり方（`Home.tick`、`App.tick` から）: 家にいて起きている間 `RATE`/時、寝ている 0.15 倍・出かけている 0.05 倍・画面を閉じている 0.5 倍。同居相手 +0.6、来客中 +0.5。料理（`home_dirty`）で洗い物、来客のあと（`bonds.end`）で少し散らかる。
- 片付け: 家事（`Home.chores`、洗剤で 1.0 / なしで 0.55 倍）と「一緒に掃除」（`home_clean`、あなたの家にいるときだけ）。たまっているものほど多く片付く（`Home.clean`）。
- 招く: 「うちに来ない？」（`invite_home`、家に行ける仲、`bond: guest_start` → `with.mode = "guest"`、`visit_hours` で帰る、「そろそろ送っていくね」= `see_off`）。来たら `Home.on_guest`: 片付いていれば好印象のことも（`home.guest_clean`、気づかないことも）、散らかっていれば性格（`traits.neat` きれい好き / `traits.carer` 世話焼き）で 気にする（`home.guest_messy_mind`、機嫌の理由に残る）/ 気にしない（`_ok`）/ 手伝い出す（`_help`、少し片付く）。来ている間はその人の場面が「あなたの家」。
- 同居相手（`Home.live_check`、同居相手と家で交流したとき、20 時間に一度・35%）: 片付いていれば `home.live_clean`、散らかっていれば `home.live_messy`（機嫌の理由）か `home.live_messy_help`（片付けてくれる）。
- セリフは `home.LINES`（共通）と性格プリセットの `home.<場面>`（7 場面 × 23 性格）。表示は `state_view.home`（目安・ことば）、トップバーの 🏠 の札から「家の様子」。

### カレンダー（スマホ）

`core/calview.py`・`GET /api/calendar?y=&m=`（どちらも 0 なら今月）。アプリ内だけのカレンダーで、カレンダー用の記録は持たず、もとの記録を読むだけ（以前のセーブもそのまま出る）。月の表（`first_wd` は月曜 0・`ndays`・`prev` / `next`）と日ごとの `days[YYYY-MM-DD]` = `{kind, at, ...}`:

- `appoint` / `favor`: 約束の記録（`appoints`）の全部（終わったものも、記録の残っている 30 日）。`appoint` に `Appoint.row`（トークの約束の欄・ホームと同じ形。欠けた項目は既定で）。頼まれごとの水やりは `t`〜`until` の毎日、都合を聞かれている（`ask`）ものは日時がまだ無いので `undated` に。
- `plan`: `planner` の予定（`text` は `Planner.label`、`id` で `/api/plan/remove`）。
- `sched`: 知っている相手の予定（`known` の kind `schedule` の `key` = `days|from|to|label|workplace` から。今日から先の、曜日の合う日に `day_match`）。いまの予定に同じものが無ければ `stale`（聞いたときの中身で出す）、`STALE_DAYS` より前に聞いたものは `old`。知らない予定は出さない。
- `people`（誘える相手: contact / visit）、`plan_dates`（予定を組める日）、`invite_to`（約束は 2 週間先まで）。

登録は新しい仕組みを作らず、画面（`static/app.js` の `calendarView`。スマホのトーク一覧の 🗓、トークの約束の欄と稼ぎ方の頼まれごとの 🗓 → `openCal(t)`）から既存の処理を呼ぶ: 誘う（`appointForm` を選んだ日で → `/api/appoint`）、頼まれごとの日時の案（`/api/appoint/answer {counter}`）、答える（`/api/appoint/answer {yes}`）、予定を足す（`/api/plan/add`）。

### 約束（アポ）

`core/appoint.py`。同居していない相手とは、約束してから会う（約束なしのお出かけ・訪問・招待は `act` で断る。同居相手はいらない）。記録は `player.json` の `appoints`。

- こちらから: トークの「📅 約束する」（`POST /api/appoint {id, t, place, do}`。日時は 30 分後〜2 週間先、行き先は表から、何をするかはその行き先でできるお出かけのコマンド。家に行ける仲なら相手の家 `visit_home` / あなたの家 `invite_home`）。時間帯の条件（`phase`）だけはその時刻で確かめる。返事は `msg_pending` の kind `appoint` で時間差（スマホを見ていればすぐのことも）。受けるかは `Appoint.reply`: その時間の相手の予定（`scheduled_scene` が外出・手が離せない・寝ているなら多くは断る `chat.appoint_busy`）、好感度・機嫌・慎重さ・家に行ける仲・`date_promise`・連絡しすぎ（`chat.appoint_yes` / `appoint_no`）。
- 相手から: 離れている連絡先の相手（好感度 45 以上）が、ときどき誘ってくる（`_maybe_invite`: 好感度・寂しさ × 性格の `approach` × その日の気分 `mood_factor`（機嫌が高いほど誘いやすく、ストレス 65 超で 0.6 倍・健康 50 未満で 0.35 倍。0.1〜1.5）。1〜5 日先、相手の予定が空いている時間。`chat.appoint_invite`）。行き先とすることは `Appoint.pick`: 選択肢ごとの重み `place_weight`（0.8〜1.5。好きなもの `LIKE_PLACES` に合う +0.25・苦手 −0.2、一緒に行った行き先の楽しさ `place_fun`（会ったときの機嫌の動き。`remember`）で −0.15〜+0.2、まだ行ったことのない所 +0.1）で少しだけ傾け、あとは偶然。性格プリセットで行き先を決め打ちしない。
- 誘いへの返し方: 「行く」「断る」（`POST /api/appoint/answer {id, yes}`）と「別の日時（・行き先）なら」（`{id, counter: {t, place, do}}` → `Appoint.counter`。状態は返事待ち `asked` に戻り、返事はいつものメッセージの時間差・すぐの返信）。相手の返事は `reply`: その時間に予定があれば多くは断る（`appoint_busy`）か、仲・機嫌しだいで近い別の時間（`_alt_time`: 相手の予定が空いていて行き先が開いている時間）を返す（`appoint_counter` → また誘われている `offered`）。予定が空いていれば、自分から誘った話の続きなので受けやすい（`date_promise` と同じ上乗せ）が、断ることも、別の案を返すこともある。やりとりは `COUNTER_MAX`（3）回まで。丸一日返事をしなければ流れる（少し寂しがる）。
- こちらからの誘いを断るときも、相手から別の日時（3 割ほどは行き先も。`pick` で好みに気持ち傾く）を返すことがある（`counter_chance`: その時間に予定があるだけなら 0.3、気が乗らないだけなら 0.12 を基準に、好感度・機嫌・性格の `approach` で上がり `caution` で下がる。0.02〜0.7）。返ってきた案は誘われているのと同じ（`offered`）で、受ける・断る・別の日時なら、で答える。セリフは `chat.appoint_counter`。
- 相手の側の当日は、約束したときに決まる（`_plan`、画面には出さない）: すっぽかし（仲が浅いほど・`traits.punctual` が低いほど）、遅刻（`punctual` しだいで 5〜60 分）。体調不良のキャンセルは 3 時間前ごろに健康しだい（`chat.appoint_cancel`）。
- 当日は自分で出向く: 約束の場所へは、ふつうの外出（`solo.start("out", place)`。`POST /api/appoint/go {id}` は行き先を約束の場所にした外出を始めるだけ）。`Appoint.live` → `_tick` が state_view のたびに、あなたが約束の場所にいるか（`Appoint.here`: 外出中で `presence.place` が約束の場所 / あなたの家なら家にいる）を見て、着いた時刻（`arrived`。約束の 3 時間前から数え、時刻の前に離れれば消す）を覚える。約束の時刻を過ぎて、その場所にいて相手が来ていれば会う（`_meet`: 外出を終えて `act(do, opts={appointment})`。条件は約束のときに済んでいるので見ない。`bonds.realize` は通る）。相手が遅れていれば着いて待つ（`waiting`）。相手が来ないなら 30 分（`GIVE_UP`）待ってあきらめる（`stood_up`、あとで謝りのメッセージ `chat.appoint_sorry` が来ることも）。着いたのが 10 分以上遅ければ少し機嫌を損ねる。45 分（`GRACE`）たっても約束の場所にいなければ（画面を閉じていても）すっぽかし（`missed`: 機嫌・信頼・好感度が下がり、機嫌の理由と `chat.appoint_missed`）。画面を閉じていた間の外出の切り上げ（`outdoor.check_gap`）は約束の判定より先に行う。画面を開いたまま放置していても、行動パターンでは出向かない。
- 移動時間はない（一人の外出・お出かけ・合流と同じく、出かけるとすぐ着く）。入れるなら行き先の表に距離を持たせ、外出全体（偶然の出会いの時間・閉まる時刻）と合わせて扱う必要がある。
- 相手の家の約束: 約束の 3 時間前から約束の 45 分後までに相手の家へ出かけると、約束なしの訪問（`drop_in`）ではなく玄関先で待つ（`Appoint.arrive_home_of`。外出中で、行き先は `home:<id>`。家では偶然の出会いは起きない）。あなたの家に招く約束は、その時間に家にいればよい。
- 表示: `state_view.appoints`（約束の一覧と、もうすぐか `due`・約束の場所にいるか `here`・残り秒 `remain`）・`appoint_events`（着いた・会えた・キャンセル・誘い・すっぽかし）、トークの `appoints` / `appoint_choices`。「一人で」とトークの約束に「🚶 ◯◯へ出かける」、外出中の画面に「約束: ◯時 ◯◯さん（あと◯分）」。

### メッセージ（トーク）

`core/chat.py`。相手ごとのトーク（`W/chats/<cid>.json`: `seen_t` と `items[{t, who: me/her/sys, kind, text, read_t}]`）。

- 自撮りを頼む（`ask_selfie`）: 送ってくれるかは 0.15 + 好感度・機嫌・ドキドキ − 恥じらい（家に行ける仲以上は少し上がる。3〜85%）。送ってくれたら返信に自撮りが添えられる（`chat.selfie_yes`）。断られる（`selfie_no`）、3 時間に 2 回より多く頼むと嫌がられる（`selfie_pester`. 機嫌 −4・好感度 −1）。
- 届いたメッセージへの返事（選択肢）は、働きかけの欄のほか、スマホのトークの下でも選べる。
- 送る種類 `KINDS`（おはよう・おやすみ・ありがとう・ごめんね・雑談・最近どう？・相談・からかう・甘える・会おうよ・写真・スタンプ・自撮り送って・今いい？・お疲れさま・大丈夫？・今何してる？・返事まだ？）。`POST /api/chat/send {id, kind}` → `act("message", opts.msg_kind)` → `_send_later`（トークに要約、`msg_pending.kind`）。
- 返信は `deliver_due` → `_chat_reply` → `chat.reply`（種類 × 状況: 連絡しすぎ・夜中・理由の有無・仲の深さ・機嫌）。謝る（`apology`）は連絡しすぎより先に見て, 連絡の回数（`_phoned`）にも数えない。連絡しすぎで返したときは, あなたのせいの理由（「〜からの連絡が多くて、少し疲れた」. `told`）を残すので, 謝れば和らぐ。知らせ（画面の側 `notifyCall`）: 話しかけ・返事待ちのメッセージ（`approaches`）と出先で声をかけられた（`street_pending.type = call`）を, 同じものは一度だけ, 画面の知らせ・音（`chime(strong)`: そばで話しかけられた・声をかけられたは 3 音）・振動（`navigator.vibrate`）・画面を見ていないときはタブの題名の点滅とブラウザの通知（`Notification`。設定でオンにしたときだけ, 許可を聞く）で知らせる。返事をするまで 2 分ごとに一度だけ音で知らせ直す（`callRemind`）。表示の設定は `callSound` / `callRemind` / `vibrate` / `browserNotify`。一人の外出の効き目: 行き先の体の使い方 `places.EFFORT`（山 2・遊園地 1.5・海 1.3・丘 1.2）を疲れと運動（`body.move_rate` / `offline._move`）にかける。雨・雪の日に屋外の行き先で過ごすと `body.add_wet`（その日の `today.wet`）→ `body.risk` の weather（0.02 + 0.01 × 時間, 上限 0.05）。カフェは体力 +3/時（3 時間まで）。出先の立ち話（自分で選んだとき）は会話 +0.3。離れている相手からのメッセージは時刻の重み（`presence.hour_factor`: 1〜6 時 0.03, 6〜7:30・0〜1 時 0.3, 23 時〜 0.6）を掛け, 閉じていた間のメッセージは相手が起きていて手が空いている 30 分刻みの時間から選ぶ（`offline._awake_slots`）。予定に睡眠（`asleep`）が一つもないキャラは, 予定が一致しない 1:00〜7:00 を寝ていることにする（`engine.DEFAULT_SLEEP`）。既読（`read_t`）、来ないとき既読だけ。「会おう」に応じると `date_promise`（半日のうちに約束を持ちかけると受けてもらいやすい）。セリフは性格プリセットの `chat.<場面>`（`chat.LINES` が共通）。
- 受け止め方（`core/manners.py`。現実的に、めんどくさく）: 送った時点のこと（`Manners.on_send` → `msg_pending.meta`: あいさつの時間外・2 回目、スタンプが返事か・続けて何回目か、「今何してる？」の回数）と返信のとき（`Manners.reply`）で決める。どれも効き目は `bonds.realize` を通る。
  - 謝罪（`Manners.apology` → `apply_apology`）: 見るのは 4 日以内の、解決していないあなたのせいの理由のうち一番大きいもの。点 = 0.75 − 怒り（`|delta|`）/25 − 0.15 ×（同じ `action` の理由の回数 − 1）+（機嫌 − 50）/120 +（好感度 − 50）/250 +（信頼 − 50）/300 − 0.8 ×（`traits.grudge` − 1）+（その場なら会話 × 0.08）+ 揺らぎ N(0, 0.15)。0.55 以上 quick（あなたのせいの理由を解決）・0.3 以上 half（`delta` を半分に. 残る）・0.1 以上 deeds（残る. `_too_often` なら連絡せずに 8 時間で `settle` が解決）・それ未満 refuse。半日より前の理由なら late（「今さら？」. 解決）。4 時間のうちに 2 回目は enough、3 回目からは irritated（`apologies`。連絡の回数 `_phoned` には数えない）。謝ったあと（1 日のうち）にまた連絡しすぎると `too_often_again`（機嫌 −5・信頼 −2・好感度 −1, 理由 −4. `apology_last`）。その場で謝る（`apologize`）も同じ判定で、反応の条件 `apology=quick/half/deeds/refuse/late/enough/irritated`（`none` なら従来の cause の反応）。性格の `traits.grudge`（根に持つ 1.25〜さっぱり 0.8）。
  - お礼: 心当たり `favors`（会った・お金を貸した・相談にのった・自撮り・おごった・看病. 24 時間）。まだお礼を言っていないものがあれば効き、言ったものだけなら `thanks_again`、何もなければ `thanks_what`。謝ったあと（`apology_last` が 1 日のうちで、まだお礼を言っていない心当たりより新しい）のお礼は謝罪の結果しだい（`Manners._thanks_forgave`）: quick・受け入れた late（`s` 0.3 以上. `s` の無い以前の記録は受け入れたもの）は小さく効く（2 回目から `thanks_again`）、half は 0.5 − (grudge − 1) の確率で効き、そうでなければ `thanks_not_yet`（機嫌 −1）、deeds・refuse・broken は `thanks_unforgiven`（機嫌 −2・好感度 −0.5）。以前の判定で「え、何が？」（`thanks_what`）と返っていた、謝罪のあと 1 日のうちのお礼は、起動したとき一度だけ本来の効き目を当て直す（`Manners.rejudge_thanks`。トークの文面は書き換えず、当て直した返信の時刻を `thanks_rejudged` に覚えて二重に当てない）。返事待ちのままのお礼は、届くときに新しい判定で返る。
  - あいさつ: おはようは 13〜18 時・21 時〜が時間外、おやすみは 5〜17 時が時間外。同じ朝・同じ夜（夜は 6 時間前の日付）の 2 回目は `greet_again`。習慣（その前の 7 日のうち 5 日以上）が途切れたら、`settle`（`life.step` から）がおはようは 12 時、おやすみは翌 6 時に一度だけ見て、性格（`approach`・`absence`）と好感度しだいで機嫌の理由（−1.5）にする。
  - スタンプ: 相手のメッセージ（6 時間以内）や働きかけへの返事がスタンプだけなら `stamp_only`（話したがりの性格ほど）。1 時間のうちに 3 回目からは `stamp_spam`。
  - 今いい？: 「あとで」はストレス 70 超・機嫌が低い・揺らぎ（15%〜）。いいよなら `call_ok_until`（30 分）のうちの電話は出る確率 × 1.15（上限 0.95）、出たら機嫌 +1.5。
  - お疲れさま: 知っている予定（`knowsched`）が今日あり、終わって 3 時間のうちなら効く。大丈夫？: 聞いた出来事の悪い理由がある、または会った・やりとりしたときに具合の悪さ（健康 50 未満・機嫌 35 未満）に気づいて（`seen_down`）36 時間のうち、まだ治っていない。効き目は気配りのスキルしだい。今何してる？: 今の過ごし方（`{doing}`）、予定を知ることも（6 割）。半日に 3 回目からは `what_doing_much`（理由 −2）。
  - 返事まだ？: 返信待ちの間なら、返信はもとのメッセージに対して届き、読んだときに `nudge_bad`（機嫌 −4・好感度 −1, 理由 −2.5）か、急ぎ（約束の誘いの返事待ち・約束の 3 時間前から）なら `nudge_ok`。返信待ちでなければ `nudge_huh`。「最近どう？」の `{news}` に入る一文のかけらも性格ごと（出来事があったとき `chat.ask_how_news` の `{tell}` に出来事, 何もないとき `chat.ask_how_nothing`。無ければ共通の「〜んです。」/「特に変わりないですよ。」など）。
- 電話（出た・出なかった・折り返し）、相手からの働きかけ（`"apart": true`、オフライン中も）、それへの返事もトークに並ぶ。
- API: `GET /api/chats`（一覧・未読）、`GET /api/chat?id=`（トーク）、`POST /api/chat/seen {id}`、`state_view.chat_unread`。

### 食事と栄養（あなた）

`core/body.py`。`player.json` の `body`: `satiety`（お腹 0〜100。起きている間は 1 時間に 4、寝ている間は 1.5 減る）・`nutri`（`staple` / `protein` / `veg` 各 0〜100。数日分の蓄えで、1 日に `NUTRI_PER_DAY`（24）ずつ減る）・`meals`（食べた記録）。時間の経過は `life.tick_world` の 5 分ごとに `body.step`。空腹（30 未満）は体力の戻りを落とす（`body.stamina_mult`）。画面には自覚できる言葉だけ（`hunger_word` / `nutri_words`）。

- 自炊 `body.cook`: 持ち物の食材（`items.NUT`: お米・パン = 主食、野菜、肉と魚・卵と豆腐 = たんぱく質。1 個で `servings` 回分。買うと回数ぶん持ち物に入る）を、献立（`body.DISHES`: 使う食材と、いる料理スキル）ぶん使う。出来ばえと失敗は料理スキルしだい。家でだけ。料理スキルが伸び、洗い物が出る。
- 外食・買って食べる `body.eat_at`: いる行き先のメニュー（`body.MENUS`: 名前・値段・栄養・お腹）。行き先の表に「食べに」（`teishoku` 定食屋・`ramen`・`fastfood`・`family` ファミレス・`restaurant`。営業時間つき）と病院（`clinic`）を足した。コンビニ・スーパー・駅前は「買って食べる」（お弁当・おにぎり・サラダなど）。食べに行く店に出かけて何も選ばずに帰ると、`solo.result` の `eat` で帰る前に一番安いものを食べる。持ち物のお弁当・カップ麺は `body.eat_item`（家で）。
- API: `POST /api/meal {how: cook | out | item, id}`、`state_view.meal`（言葉・作れる献立と理由・買ってきたもの・いる行き先のメニュー）。
- 行動パターン: `do: meal` + `how`（`cook` / `out` / `buy`）+ `place`（`offline.MEAL_PLACES`）。`body.routine_meal`: 自炊は足りない栄養を補える献立（`best_dish`）、食材がなければ買い置き、それも無ければ食べない。外食・買って食べるは、閉まっている・お金が足りなければ食べない。食事の予定が無い時間は、何も食べない。既定の行動パターンに朝・昼・夕の食事を入れた。閉じていた間のお腹と栄養が食事の前後で正しく動くよう、`offline.simulate` は行動の順に `tick_world` を進める。
- 生活費 `economy.living_cost_per_day` は食費抜き（既定 1,200 円。二人暮らしの額）。以前の既定（3,000 円。食費込み）のままのワールドは、起動時に直す（`App._migrate_living_cost`。自動バックアップ。`economy.living_cost_no_food`）。

### 同時にできないこと

`App.doing_now()`（内職の途中 / 休む・家事・研鑽の途中 / 誰かとミニゲームの途中）と `App.blocked(what)`（`solo` 一人の行動 / `side_job` 内職 / `social` 誰かとすること / `game` ミニゲーム / `cook` 自炊）。いましていることがあれば、ほかのことは始められない（休んでいる途中の自炊・ミニゲームの続きは別）。理由は `state_view.blocked`（と内職は `side_job`）で押す前に画面に出し、サーバ側でも `solo.start` / `task_start` / `act`（誰かとすること。スマホでの連絡・約束での行動・働きかけへの応答は別）/ `games.start` / `body.cook` で断る。外出・仕事・寝る・席を外すの間は、もともと外出中などの画面（オーバーレイ）でほかの操作ができない。そばで話しかけられて応じたら（`answer_approach`）、一人の時間はそこで終わる（`presence.back` → `solo.finish` で結果は残る）。

### 運動（あなた）

`core/body.py` の `exercise`（0〜100。数日分の体を動かした量）。`body.step` で 1 日 `EXERCISE_PER_DAY`（30）ずつ減り、いましていることの `move_rate`（1 時間あたり `MOVE_PER_H`: ジョギング 120・ぶらぶら歩く外出 66・誰かとのお出かけ 48・見て回る 40・店 36・家事 24・その他の外出 12・仕事 2）で増える。ジョギングは一人の行動 `solo.KINDS["jog"]`（行き先 `solo.JOG_PLACES`: 公園・河川敷・街。体力を 1 時間に 8 使う）。行動パターンの外出・家事・仕事は `offline._move` でまとめて足す（`body.add_exercise`）。日付が変わるとき（`body.daily`）、運動が 20 未満なら `lazy_days`（運動不足の日数）が増え、足りていれば 2 日ずつ戻る。運動不足が続くと: 体力の上限 `stamina_cap`（100 − 3 × 日数、最大 25 下がる）・体力の戻り（3 日以上で 0.9 倍）・体調の崩しやすさ（4 日以上で `risk` の `exercise`）。画面には言葉だけ（`state_view.meal.health.exercise`）。

### 体調（あなた）

`core/body.py` の `health`（`level` 0〜3: ふつう・少しだるい・風邪・寝込む）。日付が変わるたびに `body.daily`: その日の過ごし方（`body.today`: 寝た時間・空腹の時間・外にいた時間・休んだ時間。`body.step` が数える）と、栄養の偏り・ここ 3 日の勤務・体力・雨雪の中の外出・冬から崩しやすさ `body.risk` を出し、ふつうなら崩す・不調なら治る / こじれるを決める（補正なし）。治りやすさは休み（7 時間以上寝た・休んだ）・薬（`med_until`）・看病（`care_until`）しだい。

- 体調が悪い間の不利（`body.HEALTH_MULT`）: 体力の戻り（`stamina_mult`）・仕事の給料（`work_mult` → `life.work_pay`）・スキルの伸び（`train_mult` → `life.train`）。寝込んでいると「仕事に行く」ができない。行動パターンの仕事は、風邪なら休む・早退しやすく、寝込んでいれば休む（`offline._work`）。
- 薬: 持ち物の `cold_medicine`（風邪薬。ドラッグストア・コンビニ。家計簿では「医療」）。`POST /api/medicine`。病院: 行き先 `clinic`（営業時間・定休日あり）に外出して戻ると `body.clinic`（お金がかかる。不調なら軽いところまで戻り、薬を 2 回分もらう）。
- 画面: 「一人で」の「あなた」に言葉と「💊 薬を飲む」（`state_view.meal.health`）。
- キャラの反応: 条件キー `player_sick`（0〜3）・`player_hungry`。働きかけ `worry_you`（顔色が悪いのに気づく。応じると `care: true` → `body.cared`: お粥と半日の看病）。コマンド `eat_out`（ご飯を食べに行く。行き先は食べに行く店。費用は `body.pair_cost`（二人分）、あなたも食べる `body.eat_with`。家計簿では「外食」）。どちらも効き目は `bonds.realize` を通る。

### 家計簿

`core/kakeibo.py`。あなたの財布のお金の出入りは裏ですべて記録する（`player.json` の `ledger.raw`: `{t, a: 金額, c: 分類, n: メモ}`、120 日ぶん。`life.ledger` / `life.move(..., cat, note)`。分類 `kakeibo.CATS`: 収入・食費・外食・買い物・交際費・娯楽・医療・家賃・光熱費・通信費・生活費・借りたお金・返済・株・その他）。見えるのは家計簿につけた分（`ledger.book`）だけ。

- つけるのは家事の「家計簿をつける」（`POST /api/solo/start {kind: "kakeibo"}` → `solo.kakeibo`。15 分ほど、その場で済む。家でだけ）と、行動パターンの `do: kakeibo`。日記ではつけない。
- `kakeibo.write`: まだ書いていない出入りを日ごとにまとめる。その日・前の日は正確、2 日以上前は丸まり（`_round`）、1,000 円未満の出費は「こまごました出費」にまとまる、7 日以上前は丸まりが粗くなり一部を書き漏らす（家賃・生活費と 20,000 円以上は覚えている）。
- `kakeibo.view`（`state_view.kakeibo`）: 記録した日ごとの出入り（21 日ぶん）、この 30 日の分類ごとの合計、見積もり。固定費（`fixed_per_day`: 家賃・光熱費・通信費と生活費のあなたの分、借金の利息）は記録しなくても分かる。変動費（食費・外食・買い物・交際費・娯楽など）は記録から 1 日あたりを出し、記録した日数が少ないほど・うろ覚えの日が多いほど幅を広くする（上に広め）。「1 日にどれくらい稼げばいいか」= 固定費 + 変動費 − 毎日のわずかな収入。

### 持ち物と買い物

- 店での買い物（画面を開いての外出）: 店に出かけると、品を選び終えるまでの時間（`solo.shop_minutes`: 8〜15 分 + リストの品 1 つにつき 2.5 分）がたったところで、心拍のたびの `solo.shop_tick` がその場で買い物を済ませる（`presence.solo.shop_done`。`state_view.shop_done` で知らせ、外出中の画面に結果のカード。`POST /api/shop/ack` で閉じる）。帰ったときは買い直さない（心拍の間に時間が過ぎていれば、帰ったときに済ませる）。済む前に店を出れば「まだ買い物の途中だった」（何も買わない）。「ほかの店へ」は `POST /api/solo/move {place}`（いまの外出の結果を出して、そのまま向かう）。行動パターンの買い物は今どおり、その場で買う（`solo.result` の `shop=None`）。

`core/items.py`。品物のカタログ（`CATALOG`: 値段・売っている行き先・種類・好みの印・プレゼント可否）、持ち物（`player.json` の `items`）と買うものリスト（`shop_list`）はワールドごと。

- 買い物（`solo.finish` の shopping / cafe、オフラインの流れの買い物）で `items.shop(行き先)`: リストの品がその店にあれば買う（品切れ 12%・値段 ±15%・お金が足りなければ買えない・安い物の衝動買い）。
- 家での行動: `USES`（料理=食材・お茶=お茶・おやつ=お菓子・掃除=洗剤）。無ければ効き目が落ちる（`MISSING` のひとこと）。焦がす反応（`"taken": true`）でも食材は使う。家事は洗剤、研鑽は `PRACTICE_BOOK` の本で伸びやすい（本は減らない）。
- プレゼント: `POST /api/gift {item, character}`（`engine.give_item`）。値段 1 万円以上は `expensive_gift`（「重い」と断られたら手元に残る）、それ以外は `gift`。条件キー `liked` / `disliked`（キャラクターの定義の `likes` / `dislikes`、無ければ `items.PERSONA_LIKES`）。反応キー `gift.liked_true` / `gift.disliked_true`（23 性格分）。
- API: `POST /api/items/list {id, qty}`、`state_view.items`、`boot.catalog`。

### あなたの予定（日ごと. 閉じている間の過ごし方）

`core/planner.py`。「一人で」タブの「予定」（`state_view.plan`）。保存は `player.json` の `plan`（`items` 日付つきの予定 / `fallback` 未指定時コマンド / `auto` 自動の応答の方針）。API: `POST /api/plan/add {date, at, item}`・`/api/plan/remove {id}`・`/api/plan/fallback {items}`・`/api/plan/auto {street, reply}`。
- 予定は次の予定の時刻（同じ日のうち）まで続く。過ぎた日の分は消える（`purge`）。組める先の日数は段取りのスキル（仕事・やりくりの平均）25 ごとに 1 日（明日まで〜最大 5 日先. `horizon_days`）。約束の時刻（前 30 分〜後 2 時間）には組めない。
- 閉じていた間（`offline.simulate`）: 予定を組んでいれば `Offline._plan_blocks` で, 予定 → できなければ（`Planner.cannot`: 閉まっている・入場料/外食のお金・体力・仕事の時間外・体調・アルバイトなし）未指定時コマンドを優先度順 → 設定の行動パターン → 何もしない。空き時間（`Offline._gap_blocks`）: 予定を一つも組んでいない日は設定の行動パターンどおり（未指定時コマンドがあっても）。予定を組んだ日は, 行動パターンの勤め（仕事・アルバイト）はそのとおり, それ以外は未指定時コマンド（できるもの）→ 行動パターン。以前は空き時間がすべて未指定時コマンドになり, 予定を組んでいない日に仕事をしなかった。その取りこぼしは起動時に一度だけ `Offline.retro_missed_work` で払う（`player.json` の `retro_work_v1`）: 一人の時間の記録に残る閉じていた間のまとめ（`parse_summary` で行動ごとに戻す）から, 行動パターンでは仕事の時間に未指定時コマンドらしい行動（または何も載っていない. 未指定時コマンドに休む・家で過ごすがあるときだけ）をしていたところを `work_pay(record=True)` で。払わない: その日に給料・バイト代が入っている / `work_log` に働いた時間がある / その日に仕事の記録 / 約束 / 未指定時コマンドに無い行動 / 家計簿の裏の記録（`RAW_DAYS`）より前。記録は家計簿（いまの日付で「給料（◯/◯ の分。あとから）」）・一人の時間（その日の時刻で `work` の `retro`, いまの日付で `money` の合計）。置き換わったまとめの行動は `void_parts`, その結果の一行は `void`（日記に出さない）。約束の時間は約束（`Offline._appoint`: 会う. 効き目は `act` の `auto_weak` で良い方向を 4 割に）。次の予定で切り上げたもの（買い物・家事・研鑽などの目安より短い）は `cut`。タイムラインの各項目の `plan` に `src`（plan / fallback / routine / none / appoint）・`why`・`orig`・`at`。何も組んでいなければ今までどおり。
- 画面を開いている間に予定の時刻が来たら（`Planner.live`）, 知らせて記録するだけ（`appoint_events` に一行・あなたの記録）。
- 自動の応答: ばったりは方針どおり（25% は無難な対応に読み違える）, 効き目は半分（`street.resolve(weak=True)`）。届いたメッセージは方針があれば少しあとに自動で返す（`presence._reply(auto=True)`: 受け取り方の揺らぎ ±25・効き目は半分. トークに「・自動」）。

### オフラインモード（あなたの行動パターン）

`core/offline.py`。画面を閉じていた間（心拍が `gone_minutes` 以上途絶え、`offline.min_minutes` 以上）は、設定 `offline.days`（全体共通。曜日ごとの `[{at, do, place?, skill?}]`、各行動は次の行動の時刻まで）に沿って過ごしたことにする（`outdoor.check_gap` → `offline.simulate(最後の心拍, いま)`）。以前の `offline.work`（曜日ごとの勤務時間）は `from_work` で流れに読み替える。

- `do`: sleep / rest / home / work / out / chores / practice（`DO_LABEL`）。`out` は `place`（公共の行き先。人の家は入れない）しだいで、歩く・買い物・お茶など。仕事は `_work`（早退・叱られる・残業、同僚との出会いは無難な対応）、外出・家事・研鑽は `solo.result`（一人の時間と同じ結果）、出先の出会いは `_outing_meets`（無難な対応）。以前の `shopping` / `walk` / `cafe` は `offline.normalize` で外出 + 行き先に読み替え、設定も起動時に書き換える（`store.migrate_routine`、移行前に自動バックアップ）。
- 予定どおりにいかない（`_skip`）: 雨・雪で（屋外を歩く）外出をやめる、疲れて家事・研鑽を飛ばす、疲れきって出かけない。
- 体力: 寝る（`stamina_recover_sleep`）・休む（`stamina_recover_rest`）・家で（`stamina_recover`）で戻り、仕事・外出・家事で減る。
- 離れているキャラ（連絡先以上）から、働きかけ（`"apart": true`）がメッセージとして届くことがある。返事の遅れで機嫌が下がる量は `absence` × (1.3 − 信頼/100)。開いてから 30 分は返事ができる。
- 結果は `player.json` の `offline_report`（`timeline` に時系列、`works`・`bought`・`meets`・`messages`）。`state_view.offline_report` で一度だけ表示、`POST /api/offline/ack` で既読。画面を開いたまま放置している間は、いまは流れに沿わない。

### 行き先の表

`core/places.py`。一人の外出・誰かとのお出かけ・訪問・行動パターン・買い物の品ぞろえは、すべてこの表を参照する（`outdoor.PLACES` / `LOCATION_PLACE` は読み替えの名前）。

- 公共の行き先 `PLACES`: 名前・印・分類 `group`（近所 / お店 / 遊びに / 仕事）・屋外か・時間帯ごとの人の多さ・できること `does`（walk / shop / tea / see / work）・入場料 `fee`。近所（公園・河川敷・駅前・街）、お店（商店街・カフェ・スーパー・コンビニ・ドラッグストア・本屋・家電量販店・ショッピングモール）、遊びに（水族館・遊園地・海・山・星空の見える丘）、職場。
- 家: あなたの家（`home:me`）と、家に行ける仲の相手の家（`home:<id>`）が `Places.table()` に加わる。家では偶然の出会いは起きない。
- 営業時間（`places.HOURS` / `open_state`）: 商店街 10〜20 時、カフェ 8〜21 時（月曜休み）、スーパー・ドラッグストア 9〜22 時、本屋・家電量販店・モール 10〜21 時、水族館 9:30〜17:30、遊園地 9〜21 時、海 6〜19 時（4〜10 月）、山 6〜16 時（3〜11 月）、職場 6〜23 時。公園・河川敷・駅前・街・コンビニ・丘・家はいつでも（夜の公園は人がほとんどいないだけ。人の多さは `crowd` のまま）。閉まっている行き先は、一人の外出（`solo._place`）でも誰かとのお出かけ（`act`。`available` の `closed`）でも行けない。画面では選択肢をグレーにして「10:00から」「定休日（月曜）」「季節外」などを出す（`state_view.outdoor.places[*].open / note / hours`）。いる行き先が閉まったら出される（`outdoor.closing`、心拍のたび）: 一人ならそれまでの結果を出して街へ（外出は続く）、誰かとなら切り上げて帰る（`_closing` の記録）。約束は会う時刻に開いていること（`appoint.propose`。相手からの誘いも開いている時間だけ）。行動パターンの外出は、閉まっていれば行かず（まとめに「閉まっていた」）、閉まる時刻までしかいない。相手の家は営業時間ではなく、在宅か・時間帯（夜遅くは断られやすい）で決まる（`drop_in`）。テストは `testclock.fix_noon` で営業時間も日曜の昼で判定する（本物は `places.open_state_real`）。
- 誰かとのお出かけ（コマンドの `override.outing`）は `override.place` に行き先を持ち、`places` があれば選べる（散歩・買い物・デート・ピクニック。`POST /api/act {action, place}`。画面では行き先を選んでから誘う）。`override.location` は表示用に行き先の名前を入れる。以前の一時シーン（`location` の日本語だけ）は `places.from_location` で読み替える。
- 品ぞろえ: `items.CATALOG` の `places`（食材はスーパー・商店街・モール、洗剤はドラッグストア・スーパー・コンビニなど、本は本屋、ゲームは家電量販店）。
- セリフ: 約束なしの訪問 `drop.yes` / `drop.no`（`places.LINES`。留守・出てこないはナレーションだけ）。お出かけのセリフのキーはコマンドのまま（変えていない）。

### 外出と偶然の出会い

`core/outdoor.py`（外出・天気。行き先の表は `core/places.py`）と `core/street.py`（誰に会うか・段階・反応）。

- 外出（presence の out / work、誰かとの outing の一時シーン）は画面を開いている間だけ。心拍が途絶えたら `outdoor.check_gap()` が最後の心拍の時点で切り上げ（`come_back(at, quiet=True)`、給料もそこまで、お出かけは解散）、家で静かに過ごしていた扱い。
- 出会いは外出中に心拍のたび `outdoor.live()` で判定: 1時間あたり `outdoor.rate_*` × 行き先の人の多さ（`PLACES[...].crowd[時間帯]`）× 天気（屋外/屋内の係数）。補正なし。天気はリアル日付から（`outdoor.weather`）。
- 行き先は外出で選ぶ（`POST /api/solo/start {kind: "out", place}`。以前の `walk` / `shopping` / `cafe` も受け付ける）。誰かとのお出かけはコマンドの行き先（`override.place`）から。
- 誰に会うか: 人ごとの「よく行く場所と時間帯」（`street.haunts_of`、名前と外見から決まる）で重み付け。仕事中は同僚だけ。初めての顔は、このワールドにまだ現れていない登録キャラ n 人と新しく生成する人が 1/(n+1) ずつ（`encounters.pick_new_face`。登録キャラが残っていても新しい人に会うことがある）。`W/people.json` に記録（ここに来る習慣も付く）。
- 段階: まだ知らない → 見かけた → 会釈する仲 → 立ち話する仲 → 知り合い（ここで登録を尋ねる）。進むかはこちらの反応 × 相手の `caution` × 偶然。
- 声をかけられた / 見かけた: `presence.street_pending` に入り、`POST /api/street {choice}` で反応（chat / nod / decline、見かけたなら talk / nod / pass）。`street.TIMEOUT` 秒たつと、声をかけられたなら会釈して流し、見かけただけなら通り過ぎる。セリフは性格プリセットの `enc.call.first` / `enc.call.again` / `enc.call.known` / `enc.chat` / `enc.decline`。
- **出先での合流**（`street._join_chance` / `join`）: 一人で出かけていて、連絡先・家に行ける仲の相手と立ち話（chat / talk）をしたら、そのまま一緒に過ごす話になる（`presence.street_join`、10 分のうちに決める。`state_view.street_join`、`POST /api/street/join {yes}`）。相手から誘われる（好感度 40 以上で、好感度・寂しさ × 性格の `approach`。`enc.join.invite`）か、こちらから誘う（好感度・機嫌・家に行ける仲・慎重さしだいで断られる。`enc.join.yes` / `enc.join.no`）。合流すると一人の外出はそこまで（`solo.finish` で結果は残る）で、相手は同じ行き先の一時シーン（`override.place`、90 分）、`with.mode = meet`。好感度などは `bonds.realize` を通す。
- 外で会っている家に行ける仲の相手とは、互いの家へ（「うちに寄っていく？」`bring_home` → `guest`、「家に寄ってもいい？」`go_her_home` → `visit`。機嫌が低い・好感度 55 未満なら断られる）。相手の家に着くと、暮らしぶりが見える（`places.home_glimpse`: きれい好きか・好きなもの・懐具合がナレーションににじむ。約束なしの訪問で迎えてもらえたときも）。あなたの家なら、家の様子に反応する（`home.on_guest`）。
- 知り合いの登録は従来どおり `POST /api/encounter {yes}`。`POST /api/encounter/force {stranger}` でも試せる（設定 → データ）。

### 既定データの更新

起動時に、開いているワールドのコマンド・ミニゲーム・出来事・働きかけを、最新の既定に自動で追従させます。

- 過去の既定のまま（未編集）のものは、最新の既定に置き換えます。手を加えたものは、そのまま残します。
- 新しく増えた既定のコマンドやゲームは追加します。一度消したものは戻しません。
- 既定の `actions.json` / `minigames.json` / `events.json` / `approaches.json` を変えたときは、コミット前に `python tools/build_default_history.py` を実行して、過去の版の指紋（`defaults/default_history.json`）を更新してください。

### 性格プリセット（セリフ集）

**設定 → キャラクター** で性格を選ぶと、コマンドの反応とミニゲームのセリフがその性格の口調に変わります。
条件・効果・画像プロンプトは共通のままなので、変わるのは口調だけです。

- 既定の性格は23種類です: 素直なはにかみ屋 / 気心知れた幼馴染 / 面倒見のいい世話焼きさん / ほんわかおっとり / 箱入りお嬢様 / 気高き令嬢 / 素直になれないツンデレ / 根っからのドS / ちょっかい好きなからかい上手 / 辛口なクール / 言葉少なな無口さん / 淡々とした実務派 / 理屈っぽいリケジョ / 凛とした男前 / 元気いっぱい / 天真爛漫な自由人 / 浮世離れした不思議さん / 人懐っこい近距離派 / 人見知りの恥ずかしがり屋 / うつむきがちな卑屈屋 / 儚げで健気な病弱さん / サバサバなボクっ娘 / 甘えたがり。
  - 気高き令嬢は、「ですわ」を使わない落ち着いた貴族風です。凛とした男前は、「〜だな」「〜だろう」で話す中性的な口調です。
  - 言葉少なな無口さんは、口数が少なく、気持ちが小さな仕草ににじむタイプです（例:「……ん。（ほんの少し口元がゆるむ）」）。辛口なクールとは違い、冷たくも毒舌でもありません。
  - 淡々とした実務派は、敬語なしの事務的な口調で話します。感情も事務的な言い回しのまま報告します（例:「今の、少しうれしかった。……記録しておく」）。
  - 根っからのドSは、いつも上から目線で、あなたが困る・照れる・焦るのを楽しむ生粋のサディストです。仲が深まっても丸くならず、好意は執着の強いからかいや独占欲として表れます。ちょっかい好きなからかい上手は、同じからかうのでもじゃれ合い・親しみとしてで、やりすぎたら引きます。
  - 浮世離れした不思議さんは、唐突な発想や詩的な言い回しで会話がときどき噛み合わないタイプです（明るく奔放な自由人や、言葉少なな無口さんとは違い、よく話すけれどずれている）。
  - うつむきがちな卑屈屋は「どうせ私なんて」と自分を低く見ますが、あなたを嫌っているわけではありません。儚げで健気な病弱さんは体調を崩しやすいものの、ひねくれずに前向きです。
  - 人懐っこい近距離派は距離が近くスキンシップも平気ですが、一線は守ります。理屈っぽいリケジョは、観察・仮説・検証の言い回しで話します。
  - どれも約500場面について、1場面に1〜2通りのセリフがあります。
  - 選んだときに、LLM 用の性格説明と、あなたの呼ばれ方もプリセットに合わせられます。
- 一人称とあなたの呼び方は、**設定 → キャラクター** で固定できます。
  - 空欄なら、性格プリセットに従います（例: ボクっ娘なら「ボク」、ツンデレなら「あんた」）。
  - 入力すると、どの性格を選んでもその一人称・呼び方になります。LLM のセリフ生成にも伝えます。
  - セリフ中では、一人称を `{fp}`（言いよどみは `{fp_st}`、例:「わ、私」）、あなたを呼ぶところを `{call}` と書きます。
- **設定 → 性格・セリフ集** で、場面ごとにセリフを見て編集・複製できます（保存先は `data/personas/`）。セリフが空欄の場面は、共通のセリフになります。
- 場面のキーは、コマンドの反応なら `<コマンドid>.<キー>`、ミニゲームなら `mg.<ゲームid>.<場面>.<キー>` です。キーは各反応の `key` か、無ければ条件式から自動で作ります（例: `talk.mood_lt_35`）。
  - コマンドや反応を追加したら、`python tools/dump_line_keys.py` で全キーの一覧が出せます。
  - `python tools/check_persona.py` で、セリフ集の抜けや書式を検査できます。

### ミニゲーム

サイドの「ゲーム」タブから遊べます。1手ごとにセリフと画像が出て、パラメータも変わります。

- **野球拳**: じゃんけんで負けたほうが1枚ずつ脱いでいきます。
  - キャラが降参したらあなたの勝ち、あなたのライフ（既定3）が尽きたら負けです。
  - 好感度が足りないと断られます。
  - 段階（既定: 靴下 → リボン → キャミソール姿 → 降参）は、服装プロンプトの追記・置き換えと、外見タグの除外で定義します。
- **あっち向いてホイ**: じゃんけんの勝者が指さし、負けた側が顔をそらします。先に3本取ったほうの勝ちです。
- **脱衣麻雀**: 二人打ちの簡易麻雀です。
  - 鳴きはなく、リーチ・ツモ・ロンだけです。主要な役（十数種と役満）があり、役なしでは和了れません。ドラと裏ドラ、フリテンもあります。
  - あなたが和了るとキャラが脱ぎ、和了られるとライフが減ります。満貫以上は2段階、倍満以上は3段階進み、役満なら一気に決着します。
  - 画像は、開始・リーチ・局の終わりで生成します。キャラはシャンテン数と受け入れ枚数で打牌を選び、相手のリーチには現物で降ります。
- **コネクトフォー / ヘックス / リバーシ**: 盤面の二人対戦です。画像は開始と決着で生成し、途中のひとことは吹き出しで出します。
  - コネクトフォーは盤の上の ▼ 投入口から落とします。コマが上から落ちるアニメーション付きです。
- **ヨット**: 世界のアソビ大全のルールに準拠したダイスゲームです。
  - 5個のサイコロを1ターン最大3回振り、残すサイコロを選んで12の役を埋めます。上段が63点以上なら+35点です。
  - キャラの番は自動で進み、何を残してどの役に入れたかを表示します。

- **花札こいこい**: 48枚の正規の札と出来役（五光・四光・雨四光・三光・猪鹿蝶・赤短・青短・タネ・タン・カス・花見で一杯・月見で一杯）で遊びます。
  - 役ができたら「あがり」か「こいこい」を選びます。7文以上と、こいこい返しは倍です。
  - 既定は3局の合計文数で勝負します。
- **脱衣ポーカー**: ファイブカードドローです。
  - 交換後に「勝負」か「倍プッシュ」を選びます。倍プッシュには、キャラが降りることもあり、受けて立たれたら2段階分になります。
  - 交換後のキャラのひとことは、ブラフのこともあります。
- **ブラックジャック**: キャラがディーラーで、17以上でスタンドします。ヒット・スタンド・ダブルができ、ナチュラルは2勝分です。先に5勝したほうの勝ちです。
- **神経衰弱**: 12組24枚です。キャラの記憶力は強さと眠気で変わり、ときどき忘れます。キャラがめくった札は位置ごと表示されます。
- **ババ抜き**: 二人で遊びます。キャラの札に指をかけると表情が変わります（嘘のこともあります）。もう一度押すと引きます。表情が本当を表す確率は `hint_honesty`（既定 0.65）を性格の `traits.poker`（顔に出る 0.6〜ポーカーフェイス 1.4）で動かしたもの（− 0.25 × (poker − 1)。0.5〜0.9。`Games.honesty`）。
- **ダウト**（`core/games.py` の `_doubt_*`）: 二人ではゲーム性が薄いので、いまはゲームの一覧に出さない（定義の `"hidden": true`。`Games.view` が一覧から外す。コード・セリフ・テストは残してある）。戻すには、設定 → ミニゲーム で doubt の `"hidden": true` を消す（または false にする）。二人で 26 枚ずつ。A, 2, 3 … K, A … と順に数を言いながら、手札から 1〜4 枚を伏せて出す（嘘でもよい）。相手は「ダウト！」か「通す」。ダウトで嘘なら出した側が、本当ならダウトした側が場の札をぜんぶ引き取る。先に手札が無くなったほうの勝ち（上がる最後の札にもダウトできる）。キャラの出し方: その数を持っていれば全部本当に出し、ポーカーフェイスの性格ほどときどき 1 枚まぜて嘘も。持っていなければ 1 枚（ときどき 2 枚）で嘘。表情（`play_tell` / `play_calm`）: 嘘のとき顔に出る確率は 0.55 − 0.45 × (poker − 1) + 凡ミス率（0.15〜0.85）、本当でも 12% は落ち着かない顔。見抜き方（`_dt_her_call`）: 分かっていること（自分の手札・自分が場に出した札 `a_seen`・あなたが引き取った札のうち自分が出したもの `known_p`）から、あなたが本当にその枚数を持っていた確率を超幾何分布で数え（`_dt_p_honest`）、嘘の見込みが 0.5 + 0.012 × 場の枚数を超えたらダウト（外れたら自分が引き取るので、場が大きいほど慎重）。見込みには強さ `skill`（0.6）による揺らぎ、判断には凡ミス率（`err` 0.06 に眠気・不機嫌の上乗せ。`Games._skill`）で読み違いが入る。あなたが上がるときは必ずダウトする。キャラの一言: 嘘がばれた `caught`、ダウトが当たった `doubt_hit`・外れた `doubt_miss`、あなたのダウトが外れた `you_miss`。
- **数当て（Hit & Blow）**（`core/numeron.py`、`Games._move_numeron`）: 0〜9 の違う数字 3 つを当て合う。あなたが先に秘密の数を決め（`act: secret`）、交互に言い合う（`act: guess`。あなたが言うとキャラもすぐ言う）。数字も場所も合えばヒット、数字だけならブロー。先に 3 ヒットで勝ち（あなたが先攻なので、同じ手数で当たれば引き分け）。キャラの推理（`numeron.ai_guess`）: これまでの答えと矛盾しない候補から選び、推理の冴え（0〜1）の確率で答えの分かれ方がいちばん細かい一手（残る候補の見込み = 答えごとの候補数の二乗和 / 候補数 が小さいもの。候補 40 と全体 20 を見比べる）を選ぶ。冴えないときは候補から適当に、(1 − 冴え) × 0.6 の確率で前の手がかりを忘れて直近の 2 つだけで考え、凡ミス率で矛盾する数も言う。推理の冴え（`Games.nm_strength`）= 0.75 × 性格の `traits.reason`（推理の冴え 0.8〜1.3。控えめ）− 眠気 40 超の分 / 150 − 体力 40 未満の分 / 150 − 不機嫌（機嫌 30 未満）0.1。当てるまでの手数の目安: 冴えている 5.0 手・ふつう 5.7 手・ぼんやり 7.5 手。
- **スピード**（`core/speedcards.py`、`Games._move_speed`）: 二人で同時に出していく早さ勝負。あなたは赤（♥♦）、キャラは黒（♠♣）の 26 枚ずつ。手元に 4 枚の場札、残りは自分の山、真ん中に台札 2 つ。台札と 1 つ違い（A と K もつながる）の場札を、どちらの台札にも出せる。出したら山から補う。どちらも出せなくなったら 3 秒のカウントダウン（`SPEED_WAIT`。`speed_at` まで。画面は「スピード！まで 3・2・1」）のあと「スピード！」（お互いの山、無ければ場札から 1 枚ずつ台札へ。出した時刻 `flip_t` から 1.6 秒は台札を光らせて「あなたの山から／〜の山から」と出す）。先に出し切ったほうの勝ち。始まりは「せーの」（`countdown` 2 秒。それまで出せない `start_at`）。キャラは時刻の予定 `ai_next` で動き、画面は 0.3 秒ごとに問い合わせる（`act: tick`。`speedcards.advance` が予定の来た分だけキャラを動かし、あなたの手もその時刻で当てる。何も起きない問い合わせは状態を書き込まない）。キャラが次を出すまで（`speedcards.delay`）= (0.7 + 1.9 × (1 − 速さ)) × 0.8〜1.3 秒、速さ（`quickness`）= 0.35 + 体力 / 250 + (100 − 眠気) / 300 + (機嫌 − 50) / 300（0.05〜1）。出せる札を見落とす確率 = 0.08 + 凡ミス率（眠気・不機嫌で上がる）。目安: 元気なら 1 分に 68 枚ほど、眠くて疲れて不機嫌なら 29 枚ほど。場札はクリックで出せる台札へ、ドラッグで好きな台札へ。

こいこい・ポーカー・ブラックジャックは、`stages` を書くと脱衣ルールになり、書かなければ勝ち数か合計点の勝負になります。

麻雀・盤面・カードゲームのキャラの強さは、眠気や不機嫌で凡ミスが増えて弱くなります。

キャラはときどき「次は○○を出そうかな？」と予告してきます（本当とは限りません）。
**設定 → ミニゲーム** で、段階・セリフ・効果・プロンプトを JSON で編集できます（`data/worlds/<id>/minigames.json`）。

### 画像の出し方

**設定 → 画像生成** で切り替えます。

- **既存の画像からランダムにすぐ表示**（既定）: 合成後の Positive + Negative が完全に一致する画像がすでにあれば、そこからランダムに 1 枚をすぐ表示します。1 プロンプトあたりの上限枚数に達するまでは、裏で新しい画像も生成し、できあがったら差し替えます（generatw と同じ方式）。
- **毎回新しく生成する**: 毎回 ComfyUI で生成します。

どちらのモードでも、生成中に次のコマンドを実行したときは、同じプロンプトの既存画像があればそれをすぐ表示し、新規生成はしません。既存画像がなければ待ち行列に追加します（「生成中は既存画像で済ませる」設定でオフにできます）。

表示中の画像は 🎲 で同じプロンプトの別の画像に、⟳ で新規生成に切り替えられます。

トーク・関係性に出る顔は、外見に顔だけのタグを足して一度だけ作るアイコンです（定義の `icon`。知り合ったとき・最初に画像を出したときに作り、画像の自動表示が切れていれば作らない。設定 → キャラクターの「作り直す」、足すタグは設定 → 画像生成の `images.icon_pos` / `icon_neg`）。できるまではログの最新の画像を使います。出先で会ったとき（声をかけられた・見かけた。画面を閉じていた間も）も、登録キャラでまだ無ければ作ります。登録していない人（`people.json`）は初めて会ったときに一度だけ作ってその人の記録（`icon`）に固定し、知り合いになって登録したら定義に引き継ぎます（作り直さない. `App.make_person_icon`）。出先のカード（声をかけられた・見かけた・一緒に過ごす誘い）に顔が出ます（まだ知らない人は顔だけで、名前は「知らない人」のまま）。
索引は `data/images/index.json`（全ワールド共通）です。無ければ、全ワールドのログから作り直します。

プロンプトは次の順で合成し、重複するタグを除いて ComfyUI に送ります。

**共通 → キャラクター →（あなた）→ 服装 → 場面 → 時間帯 → 状態タグ → 行動 → 反応**

### 条件式

```
free=true, mood>=50, phase=night|midnight
```

- カンマで区切った条件は AND、`|` は OR になります
- 使えるキーは次のとおりです
  - パラメータ id
  - `activity` `location` `phase`
  - `free`（外出・睡眠・手が離せない、のどれでもない）`away` `asleep` `busy`
  - `hour` `time`（`07:30` 形式で比較）`weekday` `day`（mon..sun）`weekend`
  - `absent`（最後のふれあいからの時間）`repeat`（クールダウン中の連続回数）
  - `outfit`（着せ替え中の服の id。おまかせなら空。着せ替えの反応では着替え先）

### セリフ生成

既定では、条件に合う定型セリフを選んで表示します。
**設定 → セリフ生成** で Ollama か OpenAI 互換の API を有効にすると、選ばれた定型セリフを方向性の参考にして、LLM がセリフを書きます。
LLM の呼び出しに失敗したときは、定型セリフをそのまま使います。

### ComfyUI 側に画像を残さない

既定では、ComfyUI の output フォルダには画像を保存しません。

- 生成した画像は、ComfyUI の一時フォルダ（PreviewImage。ComfyUI の再起動で消える）を経由して受け取ります。保存するのは、このアプリの `data/images` だけです。
- カスタムワークフローの SaveImage も、送信時に自動で PreviewImage に置き換えます。
- ComfyUI 側にも残したい場合は、**設定 → 画像生成** の「ComfyUI の output フォルダにも保存する」をオンにします。保存先は `output/kurashi/` のサブフォルダです（「保存先」で変更できます）。

### カスタムワークフロー

ComfyUI で「Export (API)」した JSON を登録できます。
値に次のプレースホルダを書いておくと、生成時に置き換えます。

`%POSITIVE%` `%NEGATIVE%` `%SEED%` `%WIDTH%` `%HEIGHT%` `%STEPS%` `%CFG%` `%CKPT%` `%SAMPLER%` `%SCHEDULER%`

## 不具合を報告するとき（判断の記録と書き出し）

- 判断の記録 `core/trace.py`（`App.trace.add(cat, msg, cid, t, **値)`）: 裏で決めたことを時刻つきで 1 件 1 行。ワールドごとの `trace.dat`（JSON → zlib → 固定鍵の XOR → base64。遊ぶ人がうっかり見ないための符号化で、秘密ではない）。`KEEP_DAYS`（14 日）より古いもの・`MAX_LINES`（20,000 行）を超えた分は `TRIM_EVERY` 件ごとに捨てる。server.log には書かない。残すもの: `msg`（送ったときの返信の予定: 遅れ・返信する確率と結果・quick・too_often・連絡の多さ・機嫌など / 返事待ちに重ねた / 電話）・`deliver`（読んだ・既読だけ・延期・一日たって来ない）・`reply`（返信の場面・効き目・realize 後・許容）・`approach`（抽せんの当たり / 外れ・見送りは 30 分に一度 `every` / 候補と選ばれた id / 時間切れ）・`manners`（謝罪の判定と値・お礼）・`offline`（閉じていた間の始め・各行動と予定の決まり方 `plan`・仕事の結果・取りこぼしの払い）・`appoint` / `favor`（状態の変化. `Appoint.save` で前の状態 `_tr` と比べる）・`retro`（起動時の当て直し）。
- 書き出し `core/debugdump.py`（`POST /api/debug/dump {hours | day, cid, brief}` → `{block, lines, chars, name}`）: 要点（`git log -1` のコミット・ワールド・時刻・範囲 / あなた / 相手ごとの params・msg_pending・approach・apology_last・連絡の多さと許容・機嫌の理由・約束・頼まれごと / いちばん新しい閉じていた間のまとめ）→ 詳細（判断の記録・トーク・ログ（プロンプトは省く）・一人の時間・日記・server.log の範囲）。`MAX_CHARS` を超えたら詳細の古い方を省く。画面（設定 → データ）には中身を出さず、符号化した 1 つのブロック（`-----BEGIN KURASHI-DUMP v1 len= crc=-----` … `-----END KURASHI-DUMP-----`、76 桁で改行）をコピー / ファイルに保存するだけ。
- エラーと操作（`core/trace.py` の `error` / `op` / `client`）: API の想定外の例外（`server.call_api`）・生成ワーカーの失敗・裏のスレッドの例外（`threading.excepthook`）は、server.log に時刻つきで書き、判断の記録にもトレースバックつきで残す。書き出しでは要点のすぐ後の「エラー」の欄（`MAX_ERRORS` 件・1 件 `MAX_TB_LINES` 行まで。server.log の行数の上限とは別枠。時刻の無い以前の `[API ERROR]` も前の行の時刻で拾う。判断の記録にある生成ジョブの失敗は重ねない）に入れ、件数と最新の 1 行は要点の頭にも。状態を変える API（POST。画面が自動で送るもの `QUIET_POST` は除く）は、あなたの操作として時刻・パス・引数の要点（`brief_args`: 長い文字列は頭だけ・一覧は件数・画像や定義まるごとは省く）・結果（ok / お断り / 見つからない / エラー）を 1 行ずつ。GET は残さない。判断の記録と同じ時系列に並ぶ。画面側（ブラウザ）のエラーは `window` の error / unhandledrejection を拾い、同じエラーは 3 秒まとめて件数にして `POST /api/client_error`（メッセージ・ファイル・行・スタックの頭 8 行・開いていた画面）。送れなくても何もしない。
- 開発者向け: 貼られたブロックは `python tools/debug_decode.py ファイル` で読む（切れ・化けを知らせ、読めたところまで出す。`--trace trace.dat` で記録を直接）。

## 生成がうまくいかないとき

画面右上のバッジ（「🖼 生成ジョブ」/「ComfyUI で生成中 …」）をクリックすると、生成ジョブの一覧が開きます。
ジョブごとに、今どの段階にいるか、経過ログ、ComfyUI の prompt_id、エラー内容が表示され、そこから取り消しもできます。
同じ内容は、サーバのコンソールと `data/server.log` にも記録されます。

| 止まっている段階 | 考えられる原因 |
|---|---|
| 前のジョブ待ち | 先に積まれたジョブを処理している。一覧の先頭のジョブを確認する |
| ComfyUI へ送信中 | ComfyUI に届いていない（アドレス/ポート、ファイアウォール、プロキシ） |
| ComfyUI のキュー待ち | ComfyUI が他の生成を処理中。ComfyUI の画面でキューを確認する |
| ComfyUI で生成中 | ComfyUI 側で処理中。ComfyUI のコンソールに進捗やエラーが出ているはず |
| 失敗 | 表示されたエラーを確認する。例: `Value not in list ckpt_name` ならチェックポイント名の誤り |

- ComfyUI との通信は、既定ではシステムのプロキシを通しません。プロキシが必要な環境では、**設定 → 画像生成** の「システムのプロキシを使う」をオンにしてください。
- 失敗のパターンは、モックで再現できます: `python tools/mock_comfy.py --fail reject|exec|hang`
