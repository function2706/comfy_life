作業の途中で「ToDoは？」などと指摘されたら、直して一言だけ返し、同じ返答の中で作業を続ける。状況を説明して止まらない。

**Why:** 2026-11-20 の kurashi S30。ToDo の指摘に答えただけで止まり、「なぜ中断する？」と言われた。

**How to apply:** 指摘が作業を止めろという意味でなければ、直したあとすぐ次のツール呼び出しへ進む。[[plan-advance-per-step]] [[autonomy-preference]]
