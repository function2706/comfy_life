kurashi でステータス・仕様を変えるときは、そのたびに「以前のセーブ・過去の記録に遡って効かせるべきか」を自分で判断し、
設計案と完了報告に「遡及: する (どこまで・一度だけ・二重にしない) / しない (理由)」を書く。

**Why:** 2026-10-30 ユーザー「ステータスや仕様変更の際にある程度遡及して対応すべきかどうかを判断するようにしてほしい」。
これまで連絡の数え方・お礼の当て直し・取りこぼした給料などで、ユーザーに言われてから遡及を足すことが何度もあった。
**How to apply:** 新しい値は以前のセーブで初めて使うときに初期値を入れる、判定の基準を変えたなら直近の過去の判定を当て直すか検討する、
お金や記録の取りこぼしは起動時に一度だけ補う、を基本形にする。関連: [[kurashi-comfy-life]] [[kurashi-realism-axiom]]
