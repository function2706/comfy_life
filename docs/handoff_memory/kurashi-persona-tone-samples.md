kurashi ([[kurashi-comfy-life]]) の性格プリセットは, アニメ・マンガ的なキャラ付けを重視しない (2026-11-02 ユーザー指示「アニメ・マンガ的なキャラ付けは重視しなくて良い」「基本的に口癖の類は不要」).
口癖・決め台詞・お約束の言い回し (「べ、別に」「えへへ」「うふふ」「〜じゃんか」の連発など) で性格を出さない. ユーザーが挙げる口調の例は雰囲気を伝えるためのもの.

**Why:** 楽天家に「じゃんか」52 本, しっかり者に「だろう」51 本などを入れてしまい, くどく不自然になった. 既存の性格にも「えへへ」「あら」「べ、別に」などが数十〜二百本あった. 現実の人のように, ふつうの話し方の中に性格がにじむほうがいい ([[kurashi-realism-axiom]]).
**How to apply:** 性格は地の口調 (タメ口/敬語) と, 何に反応しどう考えるか (内容・態度) で出す. 書いたあと特徴的な語・間投詞・語尾の出現数を数え (scratchpad の quirks.py の要領), 目立つものはふつうの言い回しに戻す (目安は数本程度). 例に無い癖も足さない. 見本は本文に出す ([[kurashi-show-line-samples]]). 手順は [[kurashi-persona-lines-process]].
