kurashi ([[kurashi-comfy-life]]) の設計の公理は「現実的であること。清濁併せ呑む」(ユーザー明言, 2026-10-18).
- 出会いは偶然であって, 出会わせるためのバイアスは入れない (知らない相手と出会わないままでもよい)
- 何回訪問・交流しても深まるとは限らない. 交流が疎かになると先に進みにくい
- プレゼントや金品は性格によっては関係を深めない (逆効果もありうる)

- **不便さ・何も起こらない時間はこのゲームの真髄** (2026-10-21). 手応えのために減らさない. ただし日記などで「後から振り返れば分かる」手がかりを残すのは歓迎.

**Why:** ゲーム的な「回数をこなせば上がる」作りを嫌い, 現実の人間関係の手応えを求めている.
**How to apply:** kurashi の新機能・調整では, 確定的な上昇やプレイヤー有利のバイアスを避け, 性格・状況・頻度・偶然で結果が揺れるようにする. 迷ったら現実ならどうなるかで決める.
