アプリの重複起動、複数のタブ・画面、画面を閉じて開き直したとき・再起動したときに状態が戻らない、のような初歩的な設計の穴は、言われる前に見つけて直す。

**Why:** 2026-10-31、内職の画面が開き直せず別の内職が始まって損をした件と、重複起動できる件で「初歩的な設計ミス」「こういうレベルは指示なく対応しておいてほしい」と言われた。補償も求められた。

**基準 (ユーザーの言葉)**: 「明らかにアプリに対して必要な作用を部分的にも一切持たない動作で、かつバグの原因となりうる設計は極力排除」。
例: 重複起動・同じデータを二つの画面で同時に操作・やりかけの作業を開き直せず新しく始められる、など。誰の得にもならず壊れる道は、言われる前に塞ぐ。

**How to apply:** 新しい機能を入れるたびに、閉じる・開き直す・再起動・二重に開く・途中で中断する、の場合を自分で確かめる。プレイヤーが損をする不具合を見つけたら、直すだけでなくゲーム内の補償 (一度だけの遡及) も考える。関連: [[kurashi-comfy-life]] [[kurashi-retroactive-judgement]]
