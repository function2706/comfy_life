kurashi で「あなた」の気持ち・不満・我慢のような心理の値を作らない。プレイヤーの心理は常に操作者 (ユーザー本人) のもの。
ゲームが動かすのはキャラクターのステータスだけ。関係性タブなどに「あなたが我慢している」といった表示も出さない。
どこまでお金・時間・体力を使うのを許すか (許容量) も操作者しだい。プレイヤー側の値は体力・お金・スキルのような実在の量に留める。

**Why:** 2026-10-30 ユーザー「不満システムは不要、プレイヤーステータスは常に操作者(僕)の心理状態のみ。没入感をむしろ損なう。変動させるのは常にキャラクターステータス」。
**How to apply:** 選択の結果は、キャラの値の変化と、あなたが実際に払うもの (お金・時間・体力) で表す。「譲ってばかりで不満がたまる」のような仕組みは作らない。
