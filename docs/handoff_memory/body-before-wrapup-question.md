wrap_up に質問 (ask) を付けると、その時点でターンが終わり、あとに本文を書けない。報告・結果・設計案・意見は、wrap_up を呼ぶ前のメッセージ本文に書く。

**Why:** 2026-10-30 ユーザー「いつもだけど、本文表示されてないぞ」。結果や設計案を「下の本文」と言いながら書かずに箱だけ出すことが何度も続いた。
**How to apply:** 質問付きの wrap_up を呼ぶターンでは、先に本文 (テキスト) を出力してから、同じメッセージの最後で wrap_up を呼ぶ。[[report-results-in-chat]] と同じ趣旨。
