# 変更履歴

## 版の決まり

- 版は `VERSION`（kurashi 直下）に書く。設定 → データ の「アプリの更新」と、起動時の表示に出る。
- 機能追加を載せた版は 2 つめの数を上げる（1.0.0 → 1.1.0）。修正だけの版は 3 つめを上げる（1.0.0 → 1.0.1）。
- 1 つの版には、機能追加だけか修正だけを、いくつでも載せてよい（混ぜない）。
- 版を上げるのは、全テストを終えたときだけ（全テストは頼まれたときに流す）。
- それまでの状態: 実装したばかりは alpha、関わる部分のテスト（変えたところと、関わるモジュールのテスト）を通したら beta（例 1.1.0beta）。
  ふだんは実装のすぐあとに部分テストまで済ませるので、beta から書く。
- 次の版の中身は下の「次の版」にためる。残件は [REMAINING.md](REMAINING.md)。
