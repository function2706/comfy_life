# 変更履歴

## 版の決まり

- 版は `VERSION`（kurashi 直下）に書く。設定 → データ の「アプリの更新」と、起動時の表示に出る。
- 機能追加を載せた版は 2 つめの数を上げる（1.0.0 → 1.1.0）。修正だけの版は 3 つめを上げる（1.0.0 → 1.0.1）。
- 1 つの版には、機能追加だけか修正だけを、いくつでも載せてよい。混ぜないのは努力目標（急ぎの修正を機能追加の版に入れることもある。そのときは区分に「機能追加・修正」と書く）。
- 版を上げるのは、全テストを終えたときだけ（全テストは頼まれたときに流す）。
- それまでの状態: 実装したばかりは alpha、関わる部分のテスト（変えたところと、関わるモジュールのテスト）を通したら beta（例 1.1.0beta）。
  ふだんは実装のすぐあとに部分テストまで済ませるので、beta から書く。
- 次の版の中身は下の「次の版」にためる。残件は [REMAINING.md](REMAINING.md)。

- A1 メッセージ: 謝るときは理由を選ぶ（あなたが相手にした・しなかったこと 105 件: 状況・メッセージの種類・コマンド。分類せず決まった順に 1 列）。相手が気にしていることなら、これまでどおりの許し方。近いことなら「それもだけど……」で少しだけ和らぐ。実際にあったが相手は気にしていないことなら「気にしてない」。心当たりがなければ「何のこと？」（別のことで怒っていれば、ずれていて少し下がる）。「近い」かは画面に出さない内部のまとまりで見る（`core/msgpick.py`、`manners.apology(pick=)`）
- A1 メッセージ: お礼も理由を選ぶ（相手がしてくれたこと 13 種類と「許してくれた」）。最近してくれて、まだお礼していないことなら効く。前のこと・もう言ったことなら軽く。していないことなら「何のお礼？」（`manners.thanks_pick`）
- A1 メッセージ: 相談は中身を選ぶ（仕事・勉強や資格・家事や暮らし・お金・体調・ほかの人との仲・将来や進路・趣味）。相手の性格に合う中身ほど頼りになる返事（世話焼きなら体調・暮らし、貯める人ならお金）。ほかの人との仲の相談は、嫉妬しやすい相手だと面白くない（`chat.consult_reply`）
- A2 メッセージ: 送る欄を分類のタブに（雑談・気持ち・誘う・写真・電話、スタンプ）。「返事まだ？」は返事待ちのときだけ。電話・「家に行ってもいい？」などは電話のタブに
- A2 メッセージ: スタンプの種類を選べる（いいね・ありがとう・びっくり・考え中・笑・OK・ごめん・ハート・がんばれ・おやすみ）。ハートは浅い仲だとなれなれしい。ごめんのスタンプは、相手が本当に怒っているときは「スタンプで済ませるの？」。ありがとうのスタンプは、最近してくれたことへの軽いお礼になる
- 遡及: これまでの機嫌の理由・お礼の心当たりは、そのまま選んだ理由と照らす（以前の、理由の印が無いものは「近い」扱い）。新しい場面（それもだけど・気にしてない・ハート 2 つ・ごめんのスタンプ・ありがとうのスタンプ・相談 3 つ）のセリフは、性格 27 種ぶん 243 行（`defaults/personas/*.json`）
- A3 読書・映画: 小説・映画はジャンルを選ぶ（本: 推理・恋愛・ホラー・動物・料理・海・紀行・星・お仕事・服 / 映画: アクション・恋愛・サスペンス・ホラー・アニメ・動物・グルメ・宇宙・スポーツ）。読み終えた・観終えたものが話題になる（`topics.BOOK_GENRES` `MOVIE_GENRES`）
- A3 読書・映画: その話題を振ると、相手がジャンルの好き・苦手を口にすることがある（「恋愛もの、けっこう好きなんです」）。近い仲・信頼・機嫌・話したがりの性格ほど言う。聞いたことは「知っていること」に残る（`topics.reveal`。会っても、メッセージでも）
- A3 読書: 「本を読む」で、小説（ジャンル）か、持っている技能の本を選ぶ。技能の本を読むのは、その技能の研鑽（本があると伸びやすい）。「研鑽」のコマンドはそのまま
- A3 移動: 電車・バス・タクシーで移動中に、小説の続き・映画の続き（スマホで）・技能の本を進められる。駅で待っている間と乗っている間だけ進む（歩く・こぐ・運転中は無理）。着いたとき・途中でやめたとき・画面を閉じていても着くまで（`geo.set_doing` `finish_doing`）
- A4 電話: 話すことを選んでかける（雑談・最近どう？・相談・お礼・謝る・話題・甘える・会おうよ）。謝る・お礼・相談・話題は、メッセージと同じく何についてかも選ぶ。出てくれたら、その話への受け答えはメッセージと同じ判定（`engine.phone_call`）
- A4 電話: 通話の長さはノリと話の受け止めで決まり、終わったらトークに「📞 電話で話した（33分ほど。楽しそうだった）」と残る（眠そう・疲れていそう・落ち着いて・素っ気ない・気まずそう も）。楽しかったときは、あとで相手から「さっきは電話ありがとう」が届くことがある
- A5 対面: 「謝る」で何を謝るかを選ぶ（メッセージと同じ一覧・判定）。近いことなら「それもですけど」、気にしていないことなら「気にしてないですよ」、別のことで怒っていれば「そのことじゃないです」
