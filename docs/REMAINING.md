#### A15 設計（11/14。段 2〜4 のぶん）

**段の切り方**: 段 2 と段 3 は同じ記録（あなたの返信の記録）を使うので、1 つのセッションで続けて作る（中）。段 4 はそのあと（軽〜中）。段 5 は別（設計から）。

**データの形**（状態の `regard` に足す。キャラごと・画面には出さない）

- `habit.reply`: 時間帯 5 つ（朝 5〜10・昼 10〜16・夕方 16〜19・夜 19〜24・夜中 0〜5）× 平日 / 休日 = 10 個の枠ごとに `{n, replied, slow}`（相手から来た働きかけの数・返した数・返すまでの分の指数移動平均）。数えるのは `presence._reply`（返した。待った時間は `waited`）と `presence._expire`（返さなかった）。自動の返事（`auto`）は数えない。
- `habit.all`: 枠を分けない同じ形（ふだんの速さ。枠の記録が少ないうちの代わり）。
- `habit.tease` / `habit.start_h`: からかいの割合（返しの種類 `tease`・`re_lol` の数 / 返した数）・あなたが連絡を始めた時刻の枠ごとの数（`engine._phoned` の `w > 0`）。
- 記録は指数で薄める（1 件ごとに 0.97 倍）ので、古い癖は 1 か月ほどで薄れる。

**判定**

- 慣れ（0〜1）= `min(1, 枠の n / (8 × 性格の覚えやすさ))`。覚えやすさ: 几帳面・マメ（`react.mame`）な人は 0.6、気にしない人（`traits.absence` が低い）は 1.5。枠の n が 4 未満なら `habit.all` を使い、それも 4 未満なら慣れ 0（いまと同じ）。
- ふだんどおりか = その枠の返す割合が 4 割未満（返さないのがふつう）/ 遅さが枠の平均の 1.5 倍まで。ふだんどおりなら、`ignored_read`・`ignored_unread`・`reply_slow` の印と、`_expire` の `mult`・`react.ignore_tick` の `k`・`react.judge` の「遅れて返す」の減点に `(1 − 0.6 × 慣れ)` を掛ける。依存度が高い（`attach.factor(dependence) > 0.3`）と、掛ける割合を半分に（分かっていても不安）。
- ふだんと違う = その枠の返す割合が 8 割以上なのに返ってこない / 平均の 3 倍より遅い。印を 1.3 倍にし、3 日に一度まで「何かあった？」（働きかけ `msg_chat` の理由 `changed` を足す。探り `unsure` と同じ作り: `msgreply.WHY_*` に 1 行ずつ・`react.WHY_TONE` は `question`）。
- からかい: `habit.tease` が 3 割以上で慣れが 0.5 以上なら、`react.judge` の `tease`・`re_lol` の点に +4（「そういう人」と分かっている）。
- 段 4（速さ合わせ）: `engine.reply_delay` の最後で、`habit.all.slow`（あなたのふだんの分）と相手の決まった待ち時間の差に、性格の係数を掛けて寄せる。係数は `regard.READING` と同じ形の表 `MATCH`（張り合う tsundere・sadist 0.6 / ふつう 0.25 / 気にしない fushigi・tenshin 0）。依存度が高いと係数を 0 に近づける。寄せる幅は ±30 分まで。`quick`（まだスマホを見ている）のときは寄せない。

**遡及**: しない（返した・返さなかったの時刻つきの記録が、過去のトークからは正確に取れない: 既読の時刻が残っていない）。これからの分から覚える。覚えるまでの間はいまと同じなので、既存のワールドで急に変わる所はない。

**当たり所**: `presence._reply` / `_expire` / `reply_land`・`react.ignore_tick` / `judge`・`engine.reply_delay` / `_phoned`・`msgreply.WHY_*`（`changed`）・`keys.py`（`WHY_LABEL` から自動で登録される）。

**テストで確かめる点**: 枠 10 個 × 返す / 返さない / 遅い の総当たりで、慣れ 0 のときはいまと同じ数値・慣れ 1 のときは軽くなる ／ 依存度が高いと軽くなり方が半分 ／ ふだんと違うときだけ重くなり「何かあった？」は 3 日に一度まで ／ 記録が薄れる ／ 開き直しても記録が残る ／ 画面のデータに `habit` が出ない ／ 速さ合わせが ±30 分を超えない・`quick` のときは寄せない（`test_reply_speed` が通る）。新しいセリフ: `ap.msg_chat.call_changed`・`msgr.why.changed.bad`（共通のセリフだけで実装し、性格別は別セッション）。
