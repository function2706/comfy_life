### メッセージの大型アップデート

ねらい: メッセージは同居前に相手と触れ合う強い手段なので充実させる。ここで作る判定（理由を選ぶ・内容を選ぶ・反応から好みが分かる）は対面の会話にも使い回す。
方針: 以降は基本 LLM を使わない（使うとしても、フリー会話モードなどのベータ機能まで）。

| 番号 | 状態 | 内容 | いまの作り / メモ |
|---|---|---|---|
| M1 | 未着手 | **謝罪・感謝の理由を選ぶ**: 相手にできるコマンド全部から「理由」を選んで謝る / お礼を言う。心当たりのない相手には正解がなく、これまでどおり「何のこと？」。効き目は、相手が納得できるかどうかで決まる（これまでどおり） | 機嫌の理由（`reasons`）とお礼の心当たり（`favors`）は相手ごとに持っている（`core/manners.py`）。選んだ理由と照らすだけで作れる |
| M2 | 未着手 | **相談の内容を選ぶ**: 一人でやること（研鑽・家事・仕事 など）を主に、ほかの候補も足す | 今は内容なしの「相談する」だけ |
| M3 | 未着手 | **雑談**: 話題を振るテーマ選び → **改修なし**（「話題を振る」で選べる）。足すもの: 映画・読書のジャンル選び / 電車・バス・タクシーの移動中の読書（研鑽の本も）・動画 / 相手の興味が、話題への反応や、性格・間柄・機嫌しだいで本人の口から分かる | ジャンルは未実装。好み（`likes`）と話題（`core/topics.py`）はある |
| M4 | 未着手 | **電話を中身のあるものに**: 話題を選んでかける（メッセージの感謝・謝罪・相談・雑談を流用してよい）。通話のあとのメッセージは相手しだい（必ずは来ない）。結果（相手の様子・通話時間など、こちらに分かること）を画面に出す | 今はかけるとすぐ終わる |
| M5 | 未着手 | **送るものの分類と画面の整理**（案。再考の余地あり）: 雑談（おはよう / おやすみ / 最近どう？ / 大丈夫？ / 今何してる？ / お疲れさま / からかう / 甘える）・感謝・謝罪・相談・話題を振る・誕生日（教えて / 教える / おめでとう）・写真（自撮り送って / 写真を送る: 景色・料理・グッズ・自撮り・動物 ほか）・スタンプ・電話（今いい？ / 電話する） | 今は 23 種類が横並び（`chat.KINDS`） |
| M6 | 未着手 | M1〜M4 の判定を対面の会話にも使う | M1〜M4 のあと |

提案（採るかは決めてもらう）:
- M1 理由の候補が多すぎるので、「最近あったこと」（ここ数日の交流・約束・頼まれごと）を上に出し、残りはコマンドの分類ごとにたたむ。
- M1 外し方を 3 段に: 的中（効く）/ 近い（「それもだけど……」で少し効く）/ 心当たりなし（「何のこと？」）。理由を知らずに謝る今の判定は残す。
- M2 相談の候補: 一人でやること（仕事・研鑽・家事・料理・お金・体調）に加えて、「ほかの人との仲」（相手によっては嫉妬）・「将来・進路」・「趣味」。相談は信頼が伸びやすく、内容が相手の得意（性格・スキル）に合うほど喜ばれる、など。
- M3 鑑賞したジャンルは「最近見た映画」「読んだ本」として話題の種になり、相手の好みと合えば盛り上がる。移動中の読書・動画は電車・バスなどの座れる移動だけ（徒歩・自転車・運転中は不可）。
- M4 通話の長さはノリ（`core/nori.py`）で決め、話題を選ぶたびに続くか切り上げるか。終わったあとに「楽しそうだった」「眠そうだった」と通話時間を出す。
- M5 「誘う」の分類を足す（会おうよ / 約束する / 家に行ってもいい？）。「返事まだ？」は返事待ちのときだけ出す。写真に「買ったもの」「仕事・勉強の様子」「空・天気」も。
