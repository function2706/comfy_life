### A20 謝る・お礼の理由を、記憶で選ぶ難しい選択肢にする（メッセージ・電話・対面）— 重
| 状態 | 追加 | 重さ | 内容 |
|---|---|---|---|
| 未着手 | 11/12（11/18 方針変更） | 重 | 謝る・お礼の理由を選ぶ欄を、**ちゃんと覚えていないと選べない難しい選択肢（記憶のクイズ）**にする。選択肢は「いつ・どこで・何を」まで書いた具体的な出来事の文。正解は実際にあった出来事、外れも記録から作る（作り物っぽくしない）。検索欄は付けない（文字で絞れると答えが浮く）。直近・よく使うものを上に寄せない。並びは毎回入れ替える。選択欄は送る欄の下の小さな場所ではなく、**別の窓（大きめのダイアログ）**で開く（メッセージ・電話・対面とも。描き直しで閉じない・選びかけが消えない） |

**作り方（11/18 にユーザーと決めた方針）**
- **細部だけ違う外れ（基本）**: 本物の出来事から細部を 1 つだけずらす（日・時間帯・中身・回数）。例: 正「火曜の夜 11 時ごろ、『おやすみ』を 3 回続けて送った」/ 外「水曜の夜…」「…『何してる？』を 3 回…」「火曜の昼…」。
- **他の人との出来事を混ぜる（基本）**: 外れの一部に、ほかのキャラクターとの本当の出来事を（名前を伏せて）混ぜる。選んだら「それ、私じゃないよね」: ただの外れより重く、性格によっては嫉妬で下がる。
- **直後に謝っても難しく**: 「さっきのこと」で当たってしまわないようにする。
  - 外れを、正解の前後（目安 1 時間）にあなたが**その相手に向けて**実際にした行動（送ったメッセージ・電話・会っていたときのコマンド）でそろえる。どれも本当にあったので、問いは「どれが気に障ったか」になる（手がかりは、画面で見えていた相手の反応だけ）。単独行動（一人で料理・散歩など）は混ぜない（相手に関係ないのが明らかで外れとして働かない）。足りなければ、同じ時間帯に他の人へ向けた行動（人違いの外れ）で補う。
  - 直後ほど細部を細かく比べる: 何日も前 = 曜日・時間帯 / 数時間前 = 時刻・回数 / 直後 = 送った文言・順番。どの時点で謝っても同じくらいの難しさに。
  - 直後の件の選択肢には時刻を書かない（いちばん新しいものを選ぶだけで当たらないように）。
  - それでも足りないとき（その時間帯の行動が 1 つしか無いなど）は、文言・順番違いの外れで数を補う。
- **段階で答える（必要なら）**: 「いつ？」→「どの連絡で？」→「何を？」と 1 段ずつ。全部合えば正解、途中まで合えば「近い」。上の 2 つで手ごたえが弱いときだけ足す。
- **外れ方で反応を変える**: 細部違い →「それじゃなくて」（いまの「近い」に相当）/ 人違い → 悪化 / 無かったこと →「何のこと？」。
- **行動ではない理由も選択肢にできる**: 「先週から一度も会っていない」「3 日の誕生日を忘れていた」「家が散らかったまま呼んだ」など、具体的な出来事の文にすれば並べられる。
- **お礼も同じ形**: 相手がしてくれたこと（`favors`）を具体的な文にし、外れは細部違い・他の人がしてくれたこと（例: 「土曜、熱のときに看病してくれた」/「日曜…」/「おかゆを作ってくれた」が別の人）。
- 公理: 選択肢に出すのは、あなたが見た・したことだけ（相手の内心の理由は出さない）。外れに使う他の人との出来事も、あなたが関わったものだけ。

**着手メモ**
- いまの形: 一覧は `core/msgpick.apology_choices`（`SITUATIONS` → `msg:<種類>` → `cmd:<コマンド>` の決まった 1 列）・`thanks_choices`（`FAVORS`）。画面は `app.js` の `chatSendBox`（`PICK_TITLE`）・`callPicker`・`pickFace`（対面はもうダイアログ）。判定は `manners.apology` / `happened` / `thanks_pick` が、機嫌の理由を `msgpick.reason_item` で項目に当てて比べる（`ACTION_ITEM`・近いもののまとまり `NEAR`）。
- 設計で決めること: 出来事の記録の形（理由・送ったメッセージ・コマンド・してくれたことに、文にするための細部 = 時刻・場所・回数・文言 を持たせる。足りなければ記録する所を足す）/ 出来事ごとの文の型と、細部をずらす規則 / 選択肢の数・外れの配分（経過時間で切り替え）/ 選んだものの送り方（いまの `reason` の id の代わりに、出題 id と選んだ番号。出題はサーバーで作って覚えておき、画面では答えが分からないようにする）/ 判定と外れ方ごとの反応・効き目 / 遡及（細部の記録が無い以前の理由・してくれたことをどう出すか）。
- 新しいセリフあり（人違い「それ、私じゃないよね」など）。性格別まで書く。
- テスト: `test_manners`（外れ方ごとの判定）、出題の整合性（正解が必ず 1 つ・外れが本物と同じにならない・他人の件はあなたが関わったものだけ・直後の件に時刻が出ない）、`test_focus_keep`（ダイアログが描き直しで閉じない）。
